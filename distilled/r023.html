一、线代期末全景图：五大板块+分值分布

先把线代的"地图"画清楚，你就知道该往哪使劲。绝大多数学校线代期末由"选择/填空 + 计算大题 + 证明题"组成，核心知识块如下：

知识板块典型大题难度通常分值占比
行列式n阶行列式计算、含参数行列式★★☆15%左右
矩阵矩阵运算、求逆、求秩★★20%左右
线性方程组解的判定、求基础解系与通解★★★20%左右
向量与相关性判断相关、求极大无关组★★★15%左右
特征值与二次型求特征值、对角化、化标准形★★★25%左右
保过策略：做题顺序很有讲究。先拿下"行列式、矩阵求逆、方程组通解"这种"算得出就得分"的题保住基本盘，再攻特征值和二次型这种"思路清晰就满分"的题。千万别在超难证明题上死磕。

二、行列式：化简通法与三大类型

行列式是线代的"运算基本功"，几乎所有板块都要用到。核心思想只有一个：用初等变换把它化成上三角（或对角线）行列式，再相乘。

2.1 最通用做法：化为上三角

  1. 把第一行第一列位置通过行/列变换做成 1（或较简单元素）。
  2. 用这个 1 消掉其下方所有元素（第 j 行 -= 第1行×倍数），让第一列除首位外全为 0。
  3. 依次往下递归，得到上三角，主对角元相乘即可。
易错点：交换两行（列）行列式变号！某一行（列）乘 k，行列式也要乘 k。很多人做着做着符号丢了、倍数丢了，白算。

2.2 三大高频类型与套路

类型特征套路
主对角类型主对角线有元素、其余零直接=主对角元之积
上/下三角、副对角类型一侧全为0对三角直接乘；副对角带 (-1)^(n(n-1)/2)
"各行之和相等"型每行元素加起来相同（如全 1 列以其为基准）先把各列加到第一列提取公因式，再化简

2.3 含参数行列式（判断可逆 / 求参数）

含参数行列式通常是让你"求 a 取何值时行列式为零 / 矩阵可逆"。做法：先把行列式化到最简，得到一个关于 a 的多项式，令其为 0 解出 a。牢记：矩阵可逆 ⟺ 行列式≠0。

技巧：含参数的题，尽量用性质把参数"独立"出来（比如某行可提出含 a 的公因子），这样多项式结构一目了然，解方程更快更准。

三、矩阵：运算、逆矩阵与秩

矩阵板块大题基本围绕"乘法正确性 + 求逆 + 求秩"展开，属于"算对就给分"的友好题型。

3.1 矩阵求逆的"配方"法

对一个 n 阶方阵 A 求逆，最通用的流程：把 [A | I] 拼成增广矩阵，用行初等变换把左边化成单位阵，右边就是 A⁻¹。

  1. 写成增广矩阵 [A | I]。
  2. 只允许行初等变换。
  3. 把左边化为单位阵，右边自动变成 A⁻¹。

3.2 求秩的套路

秩 = 最简阶梯形中非零行的行数。步骤：用行初等变换把矩阵化成阶梯形，数一数非零行即可。记住几个等价结论：

  • r(A) ≤ min(行数, 列数)
  • 可逆方阵的秩 = n（满秩）
  • r(AB) ≤ min(r(A), r(B))
高频陷阱：求秩用的变换只能是"行变换"（或者只能列变换），不能混用。题目如果给了含参数矩阵，化阶梯形时参数会让"某行是否为零"难以判断，务必分类讨论。

四、线性方程组：解的判定与通解套路

方程组是最容易失分也最容易得分的板块——因为它"有清晰流程"，但流程每一步都要严谨。分齐次（AX=0）和非齐次（AX=B）两类。

4.1 解的判定（一定要背熟）

情形条件（A是m×n，n为未知数个数）结论
齐次 AX=0r(A) < n有无穷多解（有非零解）
齐次 AX=0r(A) = n只有零解
非齐次 AX=Br(A) = r([A|B]) = n有唯一解
非齐次 AX=Br(A) = r([A|B]) < n有无穷多解
非齐次 AX=Br(A) < r([A|B])无解

4.2 求通解的标准动作

  1. 增广矩阵 [A|B]（齐次就是 A），行初等变换化到最简行阶梯形。
  2. 数秩 r，确定自由未知量个数 = n - r。
  3. 把自由未知量分别取 1（其余取 0），代回求出基础解系。
  4. 通解 = 基础解系的线性组合（齐次），或特解+基础解系组合（非齐次）。
非齐次通解公式（必记）：AX=B 的通解 = AX=B 的一个特解 + AX=0 的基础解系的任意线性组合。很多同学只求特解忘了配齐次基础解系，导致通解不完整丢分。

五、特征值与特征向量

特征值板块是"考前最容易拿分、套路最固定"的板块之一。三步走：特征多项式 → 求特征值 → 求特征向量。

5.1 标准三步

  1. 写特征多项式：|λI - A| = 0。
  2. 解出特征值：一般为 λ₁, λ₂, λ₃。
  3. 对每个 λᵢ：解齐次方程组 (λᵢI - A)X = 0，得到的基础解系就是该特征值下的线性无关特征向量。

5.2 常用结论（背下来省时间）

  • 特征值之和 = 矩阵主对角线元素之和（迹）。
  • 特征值之积 = 行列式的值。由此：λ=0 是特征值 ⟺ 行列式=0 ⟺ 矩阵不可逆。
  • A 可逆时，A⁻¹ 特征值 = 1/λ。
  • Aᵏ 的特征值 = λᵏ。

5.3 对角化判断

A 能对角化 ⟺ A 有 n 个线性无关的特征向量。常见的三角/特殊矩阵（对称阵、二重特征值）要多加注意。两个特征向量属不同特征值必线性无关。

最容易的失分点：把特征多项式写成 |A - λI| 却当成 |λI - A| 用，会差一个 (-1)ⁿ，导致特征多项式整体变号、解出的 λ 全部错误。务必要保持一致，且最后代回检查。

六、二次型与标准形

二次型大题通常给你一个二次表达式，要你化标准形（配方法）或用正交变换化标准形。这部分"步骤固定、结果可验证"，是压轴里最好拿分的。

6.1 配方法（快，但要求对称阵）

  1. 把二次型写成矩阵形式 f = XᵀAX（A 对称阵）。
  2. 用逐个变量的"完全平方"配方法逐步消去交叉项。
  3. 令新变量为线性组合，得到标准形 diag(系数)。

6.2 正交变换法

  1. 写出对称阵 A。
  2. 求 A 的特征值和单位特征向量。
  3. 把单位特征向量并成正交矩阵 Q，则 QᵀAQ = diag(特征值)。
正定判定：对称阵正定 ⟺ 各阶顺序主子式全大于 0 ⟺ 特征值全大于 0。考到"求参数使二次型正定"就是综合利用这几条。

七、向量的线性相关性与极大无关组

判断一组向量线性相关/无关，最实用的办法就是"拼成矩阵看秩"。秩相关题往往和方程组、秩结合出综合大题。

  • 向量组线性相关 ⟺ 以它们为列构成的矩阵秩 < 向量个数。
  • 无关 ⟺ 秩 = 向量个数。
  • 极大无关组：化为阶梯形，主元所在列对应的原向量就是一组极大无关组。
技巧：找极大无关组时用行变换化成阶梯形后，"主元位置"就是选中的列号。这题白送分，但千万别算错阶梯形。

八、3天冲刺安排表

下面是一套"极限 3 天保过"计划，适合只剩三天就要考的同学。每天分上午/下午/晚上三段。

天上午下午晚上
第1天行列式化简+三大类型各练2题矩阵求逆+求秩各4题做1套往年题的选填+行列式矩阵大题
第2天线性方程组判定+通解6题特征值特征向量+对角化6题二次型化标准形4题
第3天向量相关性+极大无关组4题整套限时模考1张卷错题复盘+背结论表（特征值结论等）
时间紧的关键取舍：如果你复习时间非常有限，优先级是：行列式→矩阵求逆→方程组通解→特征值，这四块占了近70%的分数且套路固定。二次型和大证明题量力而行。

九、高频易错点清单

易错点错误表现正确动作
行列式变号交换行不漏负号交换一次记得加负号
逆矩阵变换混用行列变换求逆求逆只能用行变换
特征多项式符号λI-A 写成 A-λI 自乱固定一种，最后代回验证
通解不完整非齐次只写特解特解+齐次基础解系配全
秩判断分类含参数不分类讨论参数让零值模糊时逐段讨论
对角化前提直接说可以对角化先验证有n个线性无关特征向量
保底策略：考前之夜，把上面最核心的"通法口诀"再过一遍：上三角化行列式、[A|I] 求逆、数阶梯形求秩、特解+基础解系配通解、特征多项式三步走、配方法化标准形。看到题先别慌，按套路走。

十、核心要点回顾

🎯 核心要点回顾

  • 线代五大板块：行列式、矩阵、方程组、向量相关性、特征值与二次型
  • 行列式通法：初等变换化上三角再相乘，注意变号和倍乘
  • 求逆套路：[A|I] 只用行变换，左化单位阵右即逆
  • 秩：化阶梯形数非零行，可逆⟺满秩
  • 方程组判定：r(A)与r([A|B])比较决定解的情况
  • 通解公式：非齐次通解=特解+齐次基础解系组合
  • 特征值结论：和=迹、积=行列式、不可逆⟺λ=0
  • 3天冲刺：优先行列式/求逆/通解/特征值，二次型量力而行
