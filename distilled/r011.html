一、四个核心概念

Notion看着复杂，其实就四个概念。理解了这四个，其他都是它们的组合。

概念是什么类比
Page 页面一个笔记页，可以放文字、图片、表格等任何内容一张白纸
Block 区块页面里的最小单元，一段文字、一个标题、一张图都是一个Block乐高积木
Database 数据库结构化的表格，有字段(列)和记录(行)，可切换多种视图一张Excel表
Relation 关联把两个数据库连起来，记录之间可以互相关联表与表之间的外键
理解关键：Notion里一切都是Block——你打的每段字、插的每个表格都是Block。Block可以拖动排序、嵌套、转换类型。这种"积木式"组合让Notion极其灵活，但也是它上手略慢的原因。

二、5分钟创建第一个页面

  1. 注册登录：用学校邮箱注册，教育版免费且功能全
  2. 新建页面：点左上角"+ New page"，输入标题
  3. 加内容：直接打字就是文字Block；输入"/"调出命令菜单，可加标题、待办、引用、表格等
  4. 换图标和封面：点标题上方可加emoji图标和封面图，让页面好看
  5. 嵌套页面：在页面里输入"/page"可创建子页面，形成树状结构
第一个页面建议：做个"个人主页"，把课程笔记库、读书清单、任务看板、习惯追踪都作为子页面挂在下面，作为你的Notion入口。

三、必备模板1：课程笔记库

这是大学生最该先搭的模板——把所有课程笔记集中管理，按科目+标签+日期检索。

字段类型说明
科目Select 单选高数/英语/专业课…
章节Text 文本第几章/主题
标签Multi-select 多选定义/公式/例题/易错点
日期Date 日期上课或复习日期
掌握度Select红/黄/绿
笔记正文Page(点击展开)点进去写详细内容

用法：每节课后新建一条记录，点开写正文；复习时按科目或标签筛选，红色掌握度的优先看。配合"按科目分组"视图，一眼看清每科进度。

四、必备模板2：读书清单

把在读/已读的书管起来，加评分和笔记，避免"读完就忘"。

字段类型说明
书名Title 标题主键
状态Select在读/已读/想读
评分Number(1-5)打星
类型Multi-select专业/小说/传记/工具
笔记Page点开写摘录和读后感
读完日期Date已读才填

用法：想读的加进"想读"；开始读改"在读"；读完改"已读"+打分+写笔记。用看板视图按状态分三栏，进度一目了然。

五、必备模板3：任务看板

管理作业、项目、待办，用看板视图分三栏，是最直观的任务管理方式。

字段类型说明
任务名Title主键
状态Select待办/进行中/已完成
截止日期Date排期
优先级Select高/中/低
科目/分类Select课程/社团/个人

用法：用Board看板视图按状态分栏，拖拽卡片即可改变状态。配合日历视图看截止日期分布，避免作业撞期。

六、必备模板4：习惯追踪

每日打卡+月度统计，把好习惯可视化，是坚持的好帮手。

字段类型说明
日期Date主键，每天一条
背单词Checkbox 复选打勾=完成
运动Checkbox
早起Checkbox
读书Checkbox
备注Text当天特殊情况

用法：每天一条记录，做完的习惯打勾。月度用日历视图，绿格子多的天就是好状态。坚持一个月，看满屏的勾会很有成就感。

七、Notion使用技巧

快捷键（最高频）

快捷键作用
/调出命令菜单，加任何Block
## + 空格二级标题
- + 空格无序列表
[] + 空格待办事项
> + 空格引用块
Ctrl/Cmd + D复制当前Block
拖拽Block左侧⋮⋮移动/嵌套Block

数据库视图

同一个数据库可以切多种视图，数据不变，看法不同：

  • Table 表格：默认，适合录入和编辑
  • Board 看板：按某字段分栏，适合任务/状态管理
  • Calendar 日历：按日期看，适合排期
  • Gallery 画廊：卡片式，适合带封面图的内容
  • Filter 筛选 + Group 分组：只看某科/某状态，自动归类

模板功能

数据库可以设"模板按钮"，新建记录时自动套用预设结构（如每条课程笔记都自带"定义/公式/例题"三个标题），省得每次重排。

进阶玩法：用Relation把"课程笔记库"和"任务看板"关联——某条作业可以链接到对应的课程笔记，点一下就跳过去复习，信息打通。

八、两个常见误区

误区一：过度设计

新手最容易犯的错——一上来就搭十几个数据库、七八种视图、各种关联和公式，页面华丽得像作品集，结果维护起来累死，两周后弃用。

正确做法：先从最简单的开始（一个课程笔记库+一个任务看板就够），用一周，发现哪里不顺再加。Notion的强大是"能扩展"，不是"一上来就全铺开"。

误区二：花太多时间搭页面而非用

沉迷调图标、选封面、排颜色，花在"美化系统"上的时间比真正记笔记/管任务还多。这违背了工具的初衷——工具是来帮你做事的，不是来给你"玩"的。

正确做法：页面能用就行，内容比形式重要。把时间花在"往里填内容"上，而不是"让它更好看"上。

判断标准：如果你一周里在Notion里"搭系统"超过3小时、"填内容"不足1小时，说明你已经在过度设计了。停下来，先用起来。

Notion虽好，但有人嫌慢、嫌复杂、嫌要科学上网。下面是几款免费替代品。

工具优势适合人群

语雀知识库结构清晰、编辑流畅、免费版够用喜欢"知识库"式管理的同学

十、核心要点回顾

  • 四核心概念：Page(页面)/Block(积木区块)/Database(数据库)/Relation(关联)
  • 积木式：一切都是Block，可拖动/嵌套/转换，灵活但上手略慢
  • 5分钟建页：注册→新建页面→打字+斜杠命令→加图标封面→嵌套子页面
  • 四套模板：课程笔记库(科目+标签+日期+掌握度)、读书清单(状态+评分+笔记)、任务看板(待办/进行中/已完成)、习惯追踪(每日打卡+月度统计)
  • 高频快捷键：/调命令、##标题、[]待办、拖拽⋮⋮移动Block
  • 数据库视图：Table/Board/Calendar/Gallery+筛选分组，同数据多看法
  • 模板按钮：新建记录自动套预设结构，省重排
  • 误区一过度设计：从最简单开始，用一周再扩展
  • 误区二搭页大于用：内容比形式重要，别沉迷美化
  • 免费替代：飞书(国内协作)/语雀(知识库)/Obsidian(本地双链)
