一、课程结构地图与高频考点

先看全貌。这门课分两大部分：概率论（概率论基础知识、随机变量、数字特征）和数理统计（抽样、估计、检验）。期末大题几乎都会落在下面这些固定板块上。

板块典型考点通常出现形式
事件概率条件概率、全概率、贝叶斯选择/填空/计算
一维分布五种常见分布、分布函数、密度计算大题
二维分布联合分布、边缘分布、独立性、条件分布综合大题
数字特征E(X)、D(X)、协方差、相关系数选择+计算
极限定理大数定律、中心极限定理计算（近似）
数理统计抽样分布、矩估计、极大似然、区间估计、假设检验后段大题
保过策略：优先搞定"一维分布 + 数字特征 + 二维分布 + 参数估计"这四大块，再加"全概率/贝叶斯"和"中心极限"，就能覆盖期末 85% 以上的题。抽样分布和假设检验按模板走也不难。

二、事件与概率：必背公式

这一块以小题为主，公式不多但高频。

2.1 必背公式

  • 概率加法：P(A∪B) = P(A) + P(B) − P(AB)
  • 条件概率：P(A|B) = P(AB) / P(B)
  • 乘法公式：P(AB) = P(A)·P(B|A)
  • 全概率：P(B) = Σ P(Aᵢ)·P(B|Aᵢ)
  • 贝叶斯：P(Aᵢ|B) = P(Aᵢ)·P(B|Aᵢ) / Σ P(Aⱼ)·P(B|Aⱼ)
  • 对立事件：P(Ā) = 1 − P(A)
易错点：独立 ≠ 互斥。独立是"一个发生不影响另一个概率"，互斥是"不能同时发生"。独立时 P(AB)=P(A)P(B)；互斥时 P(AB)=0。混用是概率小题的经典翻车点。

三、一维随机变量与分布

一维随机变量是最基础的"重头戏"，几乎必有计算大题。核心是"已知任务，选对分布，套对公式"。

3.1 五种常见分布（务必背熟参数和公式）

分布参数/均值/方差密度/分布特征常见背景
0-1/二项 B(n,p)E=np, D=np(1-p)n次独立重复试验合格率、命中次数
泊松 P(λ)E=λ, D=λ稀有事件计数单位时间到达数
均匀 U(a,b)E=(a+b)/2, D=(b-a)²/12密度常数 1/(b-a)等可能区间取值
指数 Exp(λ)E=1/λ, D=1/λ²无记忆性寿命、等待时间
正态 N(μ,σ²)E=μ, D=σ²对称钟形大量独立因素叠加

3.2 分布函数与密度互求

连续型：密度 f(x) 求分布函数 F(x) = ∫_{-∞}^{x} f(t)dt；由 F(x) 求密度 f(x) = F'(x)。重点会"分段写积分、注意边界"。

通用判题法：看到"n次独立、每次成功概率 p"→二项；"单位时间/单位面积稀少事件"→泊松；"随机区间等可能取值"→均匀；"寿命、等待"→指数；"大量独立微小因素之和"→正态。快速定位分布是解题第一步。

四、二维随机变量：联合分布与独立性

二维问题是期末大题的"常青树"。核心三步：算边缘分布 → 判断独立 → 求条件/概率。

4.1 边缘分布

  • 离散型：对 y 全求和得 X 的边缘分布，反之亦然
  • 连续型：f_X(x) = ∫ f(x,y) dy（对另一变量整个区间积分）

4.2 独立性判定

X、Y 独立 ⟺ 对一切 x,y 有 f(x,y)=f_X(x)·f_Y(y)（离散型用概率乘积，连续型用密度乘积）。

高频提醒：连续型独立性判断必须以"密度乘积关系"为准，光靠"看起来像"很容易错。而且独立时 E(XY)=E(X)E(Y)、D(X±Y)=D(X)+D(Y)，这是后续数字特征题的加速器。

五、期望、方差与协方差

数字特征是"保分题"，公式套对就有分。核心公式务必抄进公式表。

5.1 必背公式

  • E(X) = Σ xᵢpᵢ（离散）/ ∫ x·f(x)dx（连续）
  • E(aX+b) = aE(X)+b；E(X±Y)=E(X)±E(Y)
  • D(X) = E(X²) − [E(X)]²
  • D(aX+b) = a²D(X)
  • 协方差 Cov(X,Y) = E(XY) − E(X)E(Y)
  • 相关系数 ρ = Cov(X,Y) / (σ_X σ_Y)
技巧：算 D(X) 时，先算 E(X) 和 E(X²) 再相减，往往比直接套定义快。若题目给了分布，直接套公式即可；若给了函数关系，别忘"复合函数期望用∫g(x)f(x)dx"。

六、大数定律与中心极限定理

中心极限定理是期末最常见的大题之一，意义是"大量独立同分布随机变量之和近似正态"。套路固定：标准化 → 查表。

6.1 独立同分布中心极限

当 n 很大时，ΣXᵢ 近似服从 N(nμ, nσ²)，于是 P(ΣXᵢ ≤ x) ≈ Φ((x−nμ)/(σ√n))。查标准正态表即可。

6.2 解题三步

  1. 识别"和为 n 个独立同分布"，算出 nμ 和 nσ²。
  2. 把目标概率改写成标准化形式 Φ(z)。
  3. 查标准正态分布表得出数值。
提醒：遇到"某事件次数多大概率至少发生多少次"这类题，先想到中心极限定理，把"次数"看成 n 次试验之和，再用二项→近似的处理。这是全卷最容易"白送分"的大题之一。

七、抽样分布与参数估计

数理统计先从"样本×统计量"开始，重点是三大抽样分布和两种估计方法。

7.1 三大抽样分布

分布记号背景
χ²分布χ²(n)n个独立标准正态平方和
t分布t(n)大样本均值的标准量，尾巴更厚
F分布F(m,n)两个χ²量之比（各自自由度）

7.2 点估计：矩估计与极大似然估计

  1. 矩估计：令样本一阶矩/二阶矩等于总体对应矩，解出参数。步骤最机械，最易得分。
  2. 极大似然估计：写出似然函数 L = ∏ f(xᵢ;θ)，取对数 ln L，对 θ 求导令为 0（或直接用定义凑），解出最大化的 θ。样本量大误差小。
参数估计的大分陷阱：求极大似然时，很多同学算不出符号或在取对数后忘记"连乘变连加"。先把似然函数一步步写工整，再取对数、求导、解方程。别跳步，跳步就乱。

八、假设检验

假设检验是数理统计的压轴知识点，套路固定，关键是"写清原假设/备择假设→选统计量→查临界值→下结论"。

8.1 单总体均值检验（最常考）

情形统计量拒绝域（以右侧检验为例）
σ²已知（正态总体）Z = (X̄−μ₀)/(σ/√n)|Z| > z_{α/2}（双侧）
σ²未知（正态总体）t = (X̄−μ₀)/(S/√n)|t| > t_{α/2}(n−1)

8.2 四步走

  1. 设立假设：写出 H₀（原假设，通常=某值）和 H₁（备择假设）。
  2. 选统计量：σ²已知用 Z，σ²未知用 t。
  3. 算统计量值 + 定临界值：代入样本数据，查表比较。
  4. 下结论：落入拒绝域则拒绝 H₀，否则不拒绝。
结论措辞要规范："拒绝原假设 H₀，认为……"或"没有充分证据拒绝 H₀"。期末阅卷最看重"结论与检验对应"，别把"拒绝"写成"接受"。

十一、核心要点回顾

  • 两大半场：概率论（事件/分布/数字特征）+ 数理统计（抽样/估计/检验）
  • 事件公式：全概率、贝叶斯背熟，独立≠互斥
  • 五大分布：二项、泊松、均匀、指数、正态，参数/均值/方差背牢
  • 二维核心：边缘分布→独立性→条件分布三步走
  • 数字特征：E、D、Cov、ρ 公式抄熟，D(X)=E(X²)−E(X)²
  • 中心极限：和标准化 Φ 查表，三步可得分
  • 参数估计：矩估计机械、极大似然写清似然函数+求导
  • 假设检验：四步走（假设→统计量→临界→结论），措辞规范
