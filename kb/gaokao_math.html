一、函数与极限

1.1 函数的概念与性质

函数的定义

设数集 D ⊂ R，则称映射 f: D → R 为定义在 D 上的函数，记为 y = f(x)，x ∈ D。其中 x 称为自变量，y 称为因变量，D 称为定义域。

函数的四大性质

性质定义几何意义
有界性 存在 M > 0，对任意 x ∈ D，有 |f(x)| ≤ M 函数图像介于两条水平线之间
单调性 对任意 x₁ < x₂ ∈ D，若 f(x₁) ≤ f(x₂) 则单调递增；若 f(x₁) ≥ f(x₂) 则单调递减 图像沿x轴正向上升或下降
奇偶性 若 f(-x) = f(x)，则为偶函数；若 f(-x) = -f(x)，则为奇函数 偶函数关于y轴对称；奇函数关于原点对称
周期性 存在 T > 0，对任意 x ∈ D，有 f(x+T) = f(x) 图像每隔T重复出现
常见函数类型：幂函数、指数函数、对数函数、三角函数、反三角函数（以上五类称为基本初等函数）、初等函数（由基本初等函数经过有限次四则运算和复合运算构成）。

1.2 数列的极限

数列极限的 ε-N 定义

设 {xₙ} 为一数列，如果存在常数 a，对于任意给定的正数 ε（不论它多么小），总存在正整数 N，使得当 n > N 时，不等式 |xₙ - a| < ε 都成立，那么就称常数 a 是数列 {xₙ} 的极限，记为 lim xₙ = a (n → ∞)。

收敛数列的性质

  • 唯一性：如果数列收敛，那么它的极限唯一
  • 有界性：收敛数列一定有界（逆命题不成立）
  • 保号性：如果 lim xₙ = a 且 a > 0（或 a < 0），那么存在 N > 0，当 n > N 时，xₙ > 0（或 xₙ < 0）
  • 子数列收敛性：如果数列收敛于 a，那么它的任一子数列也收敛于 a

1.3 函数的极限

函数极限的类型

极限类型定义（ε-δ / ε-X 语言）
lim f(x) = A (x → x₀) ∀ε > 0, ∃δ > 0, 当 0 < |x - x₀| < δ 时，|f(x) - A| < ε
lim f(x) = A (x → ∞) ∀ε > 0, ∃X > 0, 当 |x| > X 时，|f(x) - A| < ε
左极限 lim f(x) = A (x → x₀⁻) x → x₀ 且 x < x₀ 时的极限
右极限 lim f(x) = A (x → x₀⁺) x → x₀ 且 x > x₀ 时的极限
重要结论：lim f(x) = A (x → x₀) 存在的充要条件是左右极限都存在且相等，即 f(x₀⁻) = f(x₀⁺) = A。分段函数在分段点的极限一定要用左右极限来判断！

1.4 极限的运算法则

极限四则运算法则
设 lim f(x) = A，lim g(x) = B，则：
① lim [f(x) ± g(x)] = A ± B
② lim [f(x) · g(x)] = A · B
③ lim [f(x) / g(x)] = A / B   (B ≠ 0)
④ lim [c · f(x)] = c · A   (c为常数)
注意：运算法则成立的前提是 f(x) 和 g(x) 的极限都存在。如果不存在，就不能直接用四则运算法则。遇到 ∞ - ∞、0 · ∞、0/0、∞/∞ 等未定式，要先变形再求极限。

1.5 两个重要极限

第一个重要极限
lim (sin x / x) = 1   (x → 0)
推广形式：lim [sin α(x) / α(x)] = 1，其中 α(x) → 0
第二个重要极限
lim (1 + 1/x)ˣ = e   (x → ∞)
lim (1 + x)^(1/x) = e   (x → 0)
推广形式：lim [1 + α(x)]^(1/α(x)) = e，其中 α(x) → 0
典型例题：求 lim (1 - 2/x)^(3x) (x → ∞)
思路：这是 1^∞ 型，用第二个重要极限。
令 t = -x/2，则 x = -2t，当 x → ∞ 时 t → ∞。
原式 = lim (1 + 1/t)^(-6t) = lim [(1 + 1/t)^t]^(-6) = e⁻⁶

1.6 无穷小与无穷大

无穷小的比较

设 α 和 β 都是在同一极限过程中的无穷小，且 α ≠ 0：

极限结果结论记号
lim (β/α) = 0β 是比 α 高阶的无穷小β = o(α)
lim (β/α) = ∞β 是比 α 低阶的无穷小—
lim (β/α) = c ≠ 0β 与 α 是同阶无穷小—
lim (β/α) = 1β 与 α 是等价无穷小β ~ α
lim (β/αᵏ) = c ≠ 0β 是 α 的 k 阶无穷小—
常用等价无穷小（x → 0 时）：
sin x ~ x，tan x ~ x，arcsin x ~ x，arctan x ~ x
1 - cos x ~ x²/2，eˣ - 1 ~ x，ln(1+x) ~ x
(1+x)ᵃ - 1 ~ ax，aˣ - 1 ~ x ln a
等价无穷小替换原则：只能在乘除运算中替换，加减运算中不能随便替换！如果要在加减中替换，需要满足一定条件（替换后结果不为0），建议初学者只在乘除时用。

1.7 函数的连续性

函数在某点连续的定义

函数 y = f(x) 在点 x₀ 处连续 ⟺ lim f(x) = f(x₀) (x → x₀)
即同时满足三个条件：① f(x₀) 有定义；② lim f(x) 存在；③ 极限值等于函数值。

间断点的分类

类型定义例子
第一类间断点 左右极限都存在 可去间断点（左右极限相等但不等于函数值）
跳跃间断点（左右极限不相等）
第二类间断点 左右极限至少有一个不存在 无穷间断点（极限为无穷大）
振荡间断点（极限振荡不存在）

闭区间上连续函数的性质

  • 最大值最小值定理：闭区间上的连续函数一定有最大值和最小值
  • 有界性定理：闭区间上的连续函数一定在该区间上有界
  • 零点定理：f(x) 在 [a,b] 上连续，且 f(a)·f(b) < 0，则至少存在一点 ξ ∈ (a,b)，使 f(ξ) = 0
  • 介值定理：f(x) 在 [a,b] 上连续，且 f(a) ≠ f(b)，则对介于 f(a) 与 f(b) 之间的任意数 C，至少存在一点 ξ ∈ (a,b)，使 f(ξ) = C
典型例题：证明方程 x³ - 4x² + 1 = 0 在 (0,1) 内至少有一个实根
思路：用零点定理。
设 f(x) = x³ - 4x² + 1，f(x) 在 [0,1] 上连续。
f(0) = 1 > 0，f(1) = 1 - 4 + 1 = -2 < 0
由零点定理，存在 ξ ∈ (0,1)，使得 f(ξ) = 0。证毕。

二、导数与微分

2.1 导数的定义

导数定义式

函数 y = f(x) 在点 x₀ 处的导数：
f'(x₀) = lim [f(x₀+Δx) - f(x₀)] / Δx   (Δx → 0)
等价形式：f'(x₀) = lim [f(x) - f(x₀)] / (x - x₀)   (x → x₀)

单侧导数

  • 左导数：f'₋(x₀) = lim [f(x₀+Δx) - f(x₀)] / Δx   (Δx → 0⁻)
  • 右导数：f'₊(x₀) = lim [f(x₀+Δx) - f(x₀)] / Δx   (Δx → 0⁺)
  • 函数在某点可导 ⟺ 左右导数存在且相等
可导与连续的关系：可导必连续，连续不一定可导。
即：可导 ⇒ 连续，但连续 ≠> 可导（反例：y = |x| 在 x = 0 处连续但不可导）。

2.2 导数的几何意义

函数 y = f(x) 在点 x₀ 处的导数 f'(x₀) 的几何意义是曲线 y = f(x) 在点 M(x₀, f(x₀)) 处的切线斜率。

  • 切线方程：y - f(x₀) = f'(x₀)(x - x₀)
  • 法线方程：y - f(x₀) = -1/f'(x₀) · (x - x₀)   (f'(x₀) ≠ 0)

2.3 基本求导公式

基本初等函数求导公式
① (C)' = 0  （常数的导数为0）
② (xᵘ)' = u·xᵘ⁻¹  （幂函数）
③ (sin x)' = cos x
④ (cos x)' = -sin x
⑤ (tan x)' = sec²x
⑥ (cot x)' = -csc²x
⑦ (sec x)' = sec x · tan x
⑧ (csc x)' = -csc x · cot x
⑨ (aˣ)' = aˣ · ln a
⑩ (eˣ)' = eˣ
⑪ (logₐx)' = 1/(x·ln a)
⑫ (ln x)' = 1/x
⑬ (arcsin x)' = 1/√(1-x²)
⑭ (arccos x)' = -1/√(1-x²)
⑮ (arctan x)' = 1/(1+x²)
⑯ (arccot x)' = -1/(1+x²)

2.4 求导法则

四则运算法则

设 u = u(x), v = v(x) 都可导，则：
① (u ± v)' = u' ± v'
② (cu)' = cu'  （c为常数）
③ (uv)' = u'v + uv'
④ (u/v)' = (u'v - uv') / v²   (v ≠ 0)

复合函数求导法则（链式法则）

链式法则

设 y = f(u)，u = g(x)，且 f(u) 和 g(x) 都可导，则复合函数 y = f[g(x)] 的导数为：
dy/dx = dy/du · du/dx = f'(u) · g'(x)

典型例题：求 y = sin(x²) 的导数
思路：令 u = x²，则 y = sin u
y' = (sin u)' · (x²)' = cos u · 2x = 2x · cos(x²)

2.5 隐函数求导

由方程 F(x, y) = 0 确定的隐函数 y = y(x)，求导方法：

  1. 方程两边同时对 x 求导，注意 y 是 x 的函数（要用链式法则）
  2. 解出 y' 即可
典型例题：求由方程 eʸ + xy - e = 0 确定的隐函数的导数 y'
思路：方程两边对 x 求导
eʸ · y' + (y + x·y') - 0 = 0
整理：y'(eʸ + x) + y = 0
解得：y' = -y / (eʸ + x)

2.6 参数方程求导

设参数方程 {x = φ(t); y = ψ(t)}，则：
dy/dx = (dy/dt) / (dx/dt) = ψ'(t) / φ'(t)   (φ'(t) ≠ 0)

二阶导数：d²y/dx² = [ψ''(t)φ'(t) - ψ'(t)φ''(t)] / [φ'(t)]³

2.7 高阶导数

函数 y = f(x) 的导数 f'(x) 仍然是 x 的函数，它的导数称为二阶导数，记为 f''(x) 或 d²y/dx²。以此类推。

常用高阶导数公式：
① (eˣ)⁽ⁿ⁾ = eˣ
② (aˣ)⁽ⁿ⁾ = aˣ · (ln a)ⁿ
③ (sin x)⁽ⁿ⁾ = sin(x + nπ/2)
④ (cos x)⁽ⁿ⁾ = cos(x + nπ/2)
⑤ (xᵐ)⁽ⁿ⁾ = m(m-1)...(m-n+1)xᵐ⁻ⁿ   (n ≤ m)
⑥ [ln(1+x)]⁽ⁿ⁾ = (-1)ⁿ⁻¹ · (n-1)! / (1+x)ⁿ
⑦ 莱布尼茨公式：(uv)⁽ⁿ⁾ = Σ C(n,k) · u⁽ᵏ⁾ · v⁽ⁿ⁻ᵏ⁾

2.8 微分

微分的定义

设函数 y = f(x) 在某区间内有定义，x₀ 及 x₀+Δx 在该区间内。如果增量 Δy = f(x₀+Δx) - f(x₀) 可表示为 Δy = A·Δx + o(Δx)，其中 A 是不依赖于 Δx 的常数，则称 y = f(x) 在点 x₀ 处是可微的，而 A·Δx 叫做函数在点 x₀ 处相应于自变量增量 Δx 的微分，记作 dy，即 dy = A·Δx = f'(x₀)dx。

可微与可导的关系：函数 f(x) 在点 x₀ 处可微 ⟺ f(x) 在点 x₀ 处可导，且 dy = f'(x₀)dx。一元函数中，可微和可导是等价的。

三、微分中值定理与导数应用

3.1 罗尔定理

罗尔（Rolle）定理

如果函数 f(x) 满足：
① 在闭区间 [a, b] 上连续；
② 在开区间 (a, b) 内可导；
③ f(a) = f(b)；
那么在 (a, b) 内至少存在一点 ξ，使得 f'(ξ) = 0。

3.2 拉格朗日中值定理

拉格朗日（Lagrange）中值定理

如果函数 f(x) 满足：
① 在闭区间 [a, b] 上连续；
② 在开区间 (a, b) 内可导；
那么在 (a, b) 内至少存在一点 ξ，使得：
f(b) - f(a) = f'(ξ)(b - a)
或写成：f'(ξ) = [f(b) - f(a)] / (b - a)

几何意义：在满足条件的曲线上，至少存在一点，该点处的切线平行于连接曲线两端点的弦。罗尔定理是拉格朗日中值定理的特殊情形（当 f(a) = f(b) 时）。
典型例题：证明当 x > 0 时，x / (1+x) < ln(1+x) < x
思路：设 f(t) = ln(1+t)，在 [0, x] 上用拉格朗日中值定理。
f(x) - f(0) = f'(ξ)·x，其中 0 < ξ < x
即 ln(1+x) = x / (1+ξ)
因为 0 < ξ < x，所以 1/(1+x) < 1/(1+ξ) < 1
因此 x/(1+x) < x/(1+ξ) < x，即 x/(1+x) < ln(1+x) < x。证毕。

3.3 洛必达法则

洛必达（L'Hospital）法则（0/0 型）

设 ① lim f(x) = 0, lim F(x) = 0 (x → x₀)
② 在 x₀ 的某去心邻域内，f'(x) 和 F'(x) 都存在，且 F'(x) ≠ 0
③ lim f'(x)/F'(x) 存在（或为无穷大）
则 lim f(x)/F(x) = lim f'(x)/F'(x) (x → x₀)

使用洛必达法则的注意事项：
① 只能用于 0/0 型或 ∞/∞ 型未定式
② 每次使用前都要检查是否还是未定式
③ 其他类型（∞-∞、0·∞、1^∞、0⁰、∞⁰）要先转化为 0/0 或 ∞/∞ 型
④ 洛必达法则不是万能的，有时会失效，需要结合其他方法（如等价无穷小替换）

3.4 函数单调性的判定

设函数 y = f(x) 在 [a, b] 上连续，在 (a, b) 内可导：

  • 如果在 (a, b) 内 f'(x) > 0，那么函数 y = f(x) 在 [a, b] 上单调增加
  • 如果在 (a, b) 内 f'(x) < 0，那么函数 y = f(x) 在 [a, b] 上单调减少

3.5 函数的极值

极值的第一充分条件

设 f(x) 在点 x₀ 处连续，且在 x₀ 的某去心邻域内可导：
① 若 x < x₀ 时 f'(x) > 0，x > x₀ 时 f'(x) < 0，则 f(x₀) 是极大值
② 若 x < x₀ 时 f'(x) < 0，x > x₀ 时 f'(x) > 0，则 f(x₀) 是极小值
③ 若 x 在 x₀ 左右两侧 f'(x) 符号不变，则 f(x₀) 不是极值

极值的第二充分条件

设 f(x) 在点 x₀ 处具有二阶导数，且 f'(x₀) = 0, f''(x₀) ≠ 0：
① 当 f''(x₀) < 0 时，f(x) 在 x₀ 处取得极大值
② 当 f''(x₀) > 0 时，f(x) 在 x₀ 处取得极小值

3.6 函数的最值

求闭区间 [a, b] 上连续函数 f(x) 的最值的步骤：

  1. 求出 f(x) 在 (a, b) 内的所有驻点和不可导点
  2. 计算 f(x) 在这些点以及端点处的函数值
  3. 比较这些函数值的大小，最大的就是最大值，最小的就是最小值

3.7 曲线的凹凸性与拐点

凹凸性的判定

设 f(x) 在 [a, b] 上连续，在 (a, b) 内具有一阶和二阶导数：
① 若在 (a, b) 内 f''(x) > 0，则 f(x) 在 [a, b] 上的图形是凹的（∪）
② 若在 (a, b) 内 f''(x) < 0，则 f(x) 在 [a, b] 上的图形是凸的（∩）

拐点：连续曲线 y = f(x) 上凹弧与凸弧的分界点称为拐点。拐点处 f''(x) = 0 或 f''(x) 不存在，且两侧 f''(x) 变号。

3.8 渐近线

类型求法例子
水平渐近线 若 lim f(x) = c (x → ∞)，则 y = c 是水平渐近线 y = arctan x 有两条水平渐近线 y = ±π/2
垂直渐近线 若 lim f(x) = ∞ (x → x₀)，则 x = x₀ 是垂直渐近线 y = 1/x 有垂直渐近线 x = 0
斜渐近线 若 lim f(x)/x = a, lim [f(x)-ax] = b (x → ∞)，则 y = ax+b 是斜渐近线 y = x + 1/x 有斜渐近线 y = x

四、不定积分

4.1 不定积分的概念

如果在区间 I 上，F'(x) = f(x)，则称 F(x) 是 f(x) 在 I 上的一个原函数。f(x) 的全体原函数称为 f(x) 的不定积分，记作：

∫ f(x) dx = F(x) + C
其中 C 为任意常数，称为积分常数。

4.2 基本积分表

基本积分公式（必须熟记！）
① ∫ k dx = kx + C  （k为常数）
② ∫ xᵘ dx = xᵘ⁺¹ / (u+1) + C   (u ≠ -1)
③ ∫ 1/x dx = ln|x| + C
④ ∫ 1/(1+x²) dx = arctan x + C
⑤ ∫ 1/√(1-x²) dx = arcsin x + C
⑥ ∫ cos x dx = sin x + C
⑦ ∫ sin x dx = -cos x + C
⑧ ∫ sec²x dx = tan x + C
⑨ ∫ csc²x dx = -cot x + C
⑩ ∫ sec x · tan x dx = sec x + C
⑪ ∫ csc x · cot x dx = -csc x + C
⑫ ∫ eˣ dx = eˣ + C
⑬ ∫ aˣ dx = aˣ / ln a + C
⑭ ∫ tan x dx = -ln|cos x| + C
⑮ ∫ cot x dx = ln|sin x| + C
⑯ ∫ sec x dx = ln|sec x + tan x| + C
⑰ ∫ csc x dx = ln|csc x - cot x| + C

4.3 换元积分法

第一类换元法（凑微分法）

第一类换元公式

设 f(u) 具有原函数 F(u)，u = φ(x) 可导，则：
∫ f[φ(x)] · φ'(x) dx = ∫ f(u) du = F[φ(x)] + C

常用凑微分形式：
dx = (1/a)d(ax+b)，x dx = (1/2)d(x²)，1/x dx = d(ln x)
eˣ dx = d(eˣ)，sin x dx = -d(cos x)，cos x dx = d(sin x)
1/√x dx = 2d(√x)，1/x² dx = -d(1/x)

第二类换元法

第二类换元公式

设 x = ψ(t) 单调、可导且 ψ'(t) ≠ 0，又 f[ψ(t)]·ψ'(t) 具有原函数，则：
∫ f(x) dx = ∫ f[ψ(t)] · ψ'(t) dt

常用代换：
① 含 √(a²-x²) → 令 x = a sin t
② 含 √(a²+x²) → 令 x = a tan t
③ 含 √(x²-a²) → 令 x = a sec t
④ 分母次数高 → 倒代换 x = 1/t
⑤ 含 n 次根号 → 令 t = n√x，即 x = tⁿ

4.4 分部积分法

分部积分公式

∫ u dv = uv - ∫ v du

选择 u 的原则（LIATE 法则）：
优先选作为 u 的顺序：
L - Logarithmic（对数函数）
I - Inverse trigonometric（反三角函数）
A - Algebraic（代数函数/多项式）
T - Trigonometric（三角函数）
E - Exponential（指数函数）
排在前面的选作 u，排在后面的选作 dv。
典型例题：求 ∫ x·eˣ dx
思路：按 LIATE，A（代数函数）在 E（指数函数）前面，选 u = x，dv = eˣ dx
则 du = dx，v = eˣ
∫ x·eˣ dx = x·eˣ - ∫ eˣ dx = x·eˣ - eˣ + C = (x-1)eˣ + C

4.5 有理函数的积分

有理函数是指两个多项式的商：P(x)/Q(x)。积分方法：

  1. 若分子次数 ≥ 分母次数，先用多项式除法化为整式+真分式
  2. 将真分式分解为部分分式之和（待定系数法）
  3. 分别积分各部分分式

五、定积分及其应用

5.1 定积分的定义

定积分定义

设函数 f(x) 在 [a, b] 上有界，将 [a, b] 任意分成 n 个小区间，在每个小区间 [xᵢ₋₁, xᵢ] 上任取一点 ξᵢ，作和 S = Σ f(ξᵢ)·Δxᵢ。记 λ = max{Δx₁, Δx₂, ..., Δxₙ}，如果当 λ → 0 时，和 S 的极限存在，且与区间的分法及点 ξᵢ 的取法无关，则称这个极限为函数 f(x) 在 [a, b] 上的定积分，记作 ∫ₐᵇ f(x) dx。

可积的充分条件：
① f(x) 在 [a, b] 上连续，则 f(x) 在 [a, b] 上可积
② f(x) 在 [a, b] 上有界且只有有限个间断点，则 f(x) 在 [a, b] 上可积

5.2 定积分的性质

① ∫ₐᵇ [f(x) ± g(x)] dx = ∫ₐᵇ f(x) dx ± ∫ₐᵇ g(x) dx
② ∫ₐᵇ k·f(x) dx = k·∫ₐᵇ f(x) dx  （k为常数）
③ ∫ₐᵇ f(x) dx = ∫ₐᶜ f(x) dx + ∫ᶜᵇ f(x) dx  （区间可加性）
④ ∫ₐᵇ 1 dx = b - a
⑤ 若 f(x) ≥ 0，则 ∫ₐᵇ f(x) dx ≥ 0   (a < b)
⑥ 若 f(x) ≥ g(x)，则 ∫ₐᵇ f(x) dx ≥ ∫ₐᵇ g(x) dx   (a < b)
⑦ |∫ₐᵇ f(x) dx| ≤ ∫ₐᵇ |f(x)| dx   (a < b)
⑧ 估值定理：若 m ≤ f(x) ≤ M，则 m(b-a) ≤ ∫ₐᵇ f(x) dx ≤ M(b-a)
⑨ 积分中值定理：∫ₐᵇ f(x) dx = f(ξ)·(b-a)，其中 ξ ∈ [a, b]

5.3 牛顿-莱布尼茨公式

牛顿-莱布尼茨公式（微积分基本公式）

如果函数 F(x) 是连续函数 f(x) 在 [a, b] 上的一个原函数，则：
∫ₐᵇ f(x) dx = F(b) - F(a) = F(x)|ₐᵇ

微积分基本定理：
变上限积分求导：d/dx ∫ₐˣ f(t) dt = f(x)
更一般地：d/dx ∫_{φ(x)}^{ψ(x)} f(t) dt = f[ψ(x)]·ψ'(x) - f[φ(x)]·φ'(x)

5.4 定积分的换元法与分部积分法

定积分换元法

∫ₐᵇ f(x) dx = ∫_α^β f[φ(t)]·φ'(t) dt
其中 x = φ(t)，a = φ(α)，b = φ(β)。
注意：换元必须换限！

定积分分部积分法

∫ₐᵇ u dv = uv|ₐᵇ - ∫ₐᵇ v du
几个重要结论：
① 奇函数在对称区间上的积分为 0：∫_{-a}^a f(x) dx = 0（f为奇函数）
② 偶函数在对称区间上的积分：∫_{-a}^a f(x) dx = 2∫₀ᵃ f(x) dx（f为偶函数）
③ 周期函数的积分：∫ₐ^{a+T} f(x) dx = ∫₀ᵀ f(x) dx
④ 华莱士公式：∫₀^{π/2} sinⁿx dx = ∫₀^{π/2} cosⁿx dx = (n-1)!!/n!! · (π/2 当n偶，1 当n奇)

5.5 反常积分

无穷限的反常积分

∫ₐ^{+∞} f(x) dx = lim ∫ₐᵇ f(x) dx   (b → +∞)
∫_{-∞}^b f(x) dx = lim ∫ₐᵇ f(x) dx   (a → -∞)
极限存在则收敛，不存在则发散。

无界函数的反常积分（瑕积分）

设 f(x) 在 (a, b] 上连续，且 lim f(x) = ∞ (x → a⁺)，则：
∫ₐᵇ f(x) dx = lim ∫_{a+ε}^b f(x) dx   (ε → 0⁺)
极限存在则收敛，不存在则发散。
重要结论：
① ∫₁^{+∞} 1/xᵖ dx：p > 1 时收敛，p ≤ 1 时发散
② ∫₀¹ 1/xᵠ dx：q < 1 时收敛，q ≥ 1 时发散

5.6 定积分的应用

平面图形的面积

直角坐标情形
由曲线 y = f(x)、y = g(x) 与直线 x = a、x = b 围成的面积：
A = ∫ₐᵇ |f(x) - g(x)| dx

旋转体的体积

绕 x 轴旋转
曲线 y = f(x)、x = a、x = b 与 x 轴围成的图形绕 x 轴旋转：
V = π ∫ₐᵇ [f(x)]² dx  （圆盘法）
绕 y 轴旋转（柱壳法）
V = 2π ∫ₐᵇ x·f(x) dx

平面曲线的弧长

① 直角坐标：s = ∫ₐᵇ √[1 + (y')²] dx
② 参数方程：s = ∫_α^β √[(x')² + (y')²] dt
典型例题：求由 y = x² 和 y = √x 围成的图形的面积
思路：先求交点，解 x² = √x 得 x = 0, x = 1
在 [0, 1] 上 √x ≥ x²
A = ∫₀¹ (√x - x²) dx = [ (2/3)x^(3/2) - x³/3 ]|₀¹ = 2/3 - 1/3 = 1/3
期末复习建议：高数上册内容多、难度大，复习时要抓住主线——极限是基础，导数是工具，积分是重点。建议按章节梳理知识框架，每章做20-30道典型题。重点掌握：洛必达法则求极限、复合函数求导、中值定理证明题、换元法和分部积分法、定积分的几何应用。
