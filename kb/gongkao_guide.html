一、公考是什么

国考 vs 省考

公务员考试主要分为国家公务员考试（国考）和各省公务员考试（省考），两者都是成为公务员的主要途径。

对比维度国考省考
组织单位国家公务员局各省省委组织部
招录单位中央机关及直属机构（如国税、海关、铁路公安等）省、市、县、乡四级机关
招考范围全国范围，不限户籍（部分岗位有户籍限制）本省为主，部分岗位有户籍限制
考试时间每年10月报名，11月底或12月初笔试多数省份参加联考（3-4月），部分省份单独命题
考试难度难度较大，竞争激烈难度相对较低（各省差异大）
薪资待遇中央部委和经济发达地区待遇好，中西部相对一般经济发达省份待遇好，差异较大
发展前景平台高，晋升空间相对大基层岗位多，晋升相对慢

学历要求具有大学专科及以上文化程度（绝大多数岗位要求本科及以上）

政治面貌部分岗位要求中共党员或共青团员

二、考试结构详解

行测（行政职业能力测验）

行测全部为客观题（选择题），考试时间120分钟，满分100分。主要考查与公务员职业密切相关的基本素质和能力要素。

模块题量（国考）参考分值建议用时
常识判断20题约0.5分/题，共10分5-8分钟
言语理解与表达40题约0.8分/题，共32分30-35分钟
数量关系10-15题约1分/题，共10-15分10-15分钟
判断推理40题约0.6-0.8分/题，共28-30分30-35分钟
资料分析20题约1分/题，共20分20-25分钟
时间紧迫：行测120分钟做130-135道题（国考副省级135题、地市级130题），平均每道题不到1分钟。做题速度和时间分配至关重要，大部分人做不完所有题目，学会取舍是行测的必修课。

申论

申论全部为主观题，考试时间150-180分钟，满分100分。主要考查阅读理解能力、综合分析能力、提出和解决问题能力、贯彻执行能力、文字表达能力。

三、行测5大模块：常识判断

题型特点

常识判断主要考查应知应会的基本知识以及运用这些知识分析判断的基本能力，涉及政治、经济、法律、历史、文化、地理、环境、自然、科技等多个领域。

  • 题量：20道题
  • 特点：范围广、内容杂、分值低、复习性价比不高
  • 目标：正确率60%左右即可，不建议花太多时间

备考策略

  1. 抓大放小，重点突破

    常识内容太多，不可能面面俱到。重点关注时政热点、法律常识、历史人文这三大块，它们占常识分值的60%以上。

  2. 利用碎片时间积累

    每天花15-20分钟看常识，不要花整块时间。利用通勤、排队等碎片时间，刷几道常识题、看几条知识点。

  3. 关注时政热点

    时政是常识判断的必考内容，通常考近一年的重大时政。平时多关注新闻联播、人民日报、半月谈，考前看时政汇总。

  4. 法律常识有侧重

    重点关注宪法、民法典、行政法、刑法中的基本概念和新修订的法律，不需要深入研究。

  5. 蒙题技巧

    ① 选项中出现绝对化表述（"全部""所有""唯一"）一般是错的；② 符合民族自豪感的选项通常是对的；③ 时间排序题可以用首尾排除法。

常识备考心态：常识是投入产出比最低的模块，不要花太多时间在上面。每天积累一点，考前集中看时政，保持60%左右的正确率就够了。把时间留给言语、判断、资料这三大提分模块。

四、行测5大模块：言语理解与表达

题型概述

言语理解与表达是行测的重头戏，题量最大（40题），分值最高（约32分）。主要考查运用语言文字进行思考和交流、迅速准确地理解和把握文字材料内涵的能力。

三大题型

题型题量（约）特点重要程度
选词填空（逻辑填空）15-20题考查词语辨析和语境理解⭐⭐⭐⭐⭐
片段阅读15-18题考查对文段主旨、细节、意图的理解⭐⭐⭐⭐⭐
语句表达2-5题语句排序、语句填空、下文推断⭐⭐⭐

选词填空备考

选词填空是言语理解中错误率最高的题型，很多人凭语感做题，结果一错一大片。

解题方法

  1. 分析语境：先读文段，理解空格前后的逻辑关系（转折、递进、因果、并列、解释说明等）
  2. 找对应点：在空格前后找提示信息，寻找与空格对应的词语或句子
  3. 辨析选项：从词义侧重、感情色彩、搭配对象、语义轻重等角度辨析词语差异
  4. 代入验证：把选中的答案代入原文，读一遍看是否通顺

高频考点

  • 转折关系：但是、然而、却、事实上、实际上 → 前后语义相反
  • 递进关系：甚至、更、乃至、不仅...而且 → 语义前轻后重
  • 因果关系：因为、所以、因此、导致 → 前后有因果联系
  • 并列关系：和、与、分号、顿号 → 前后语义相近或相关
  • 解释关系：冒号、破折号、也就是说、即 → 后文对前文进行解释
常见误区：不要用语感做题！不要用语感做题！不要用语感做题！重要的事情说三遍。逻辑填空考的是逻辑，不是语感。每一道题都要在原文中找到依据，找到那个提示你选这个答案的"证据"。

片段阅读备考

片段阅读是言语理解的拿分重点，掌握方法后正确率可以很高。

常见题型及解法

题型识别标志解题方法
主旨概括题主要内容、核心观点、中心思想、概括最准确找中心句（首尾句、转折后、对策句），同义替换
意图判断题意在说明、想表达、启示、寓意先找主旨，再判断意图（优先选合理引申，没有就选主旨）
细节理解题正确/不正确、符合/不符合、可以推出选项与原文一一对应，注意偷换概念、偷换时态、偷换数量、偷换逻辑
态度观点题作者态度、观点、评价找带有感情色彩的词语，注意转折后
标题填入题最适合的标题概括主旨+吸引眼球，新闻看导语，说明文看说明对象

片段阅读提速技巧

  • 先看问题，再读文段：带着问题读，有针对性
  • 抓关联词：转折、因果、递进、条件关联词后面是重点
  • 抓行文脉络：总分、分总、总分总，总句是重点
  • 略读举例和背景：例子、数据、背景介绍可以快速扫
  • 主题词法：正确选项一定包含文段的主题词（核心话题）

语句表达备考

  • 语句排序题：先看选项确定首句（背景引入、下定义适合做首句；关联词后半部分、指代词不适合做首句），然后找捆绑（指代词、关联词、共同信息），最后验证
  • 语句填空题：横线在开头（总领全文）、在中间（承上启下）、在结尾（总结前文），注意话题一致
  • 下文推断题：重点看尾句，尾句提出新话题，下文就围绕新话题展开

五、行测5大模块：数量关系

题型概述

数量关系主要考查理解、把握事物间量化关系和解决数量关系问题的能力，主要涉及数据关系的分析、推理、判断、运算等。这是很多考生最头疼的模块。

  • 题量：国考副省级15题，地市级10题
  • 特点：难度大、耗时长、分值高
  • 策略：不放弃但也不恋战，挑简单的做，难题蒙

常考题型

题型考查频率难度建议掌握程度
工程问题⭐⭐⭐⭐⭐⭐⭐必须掌握
经济利润问题⭐⭐⭐⭐⭐⭐⭐必须掌握
行程问题⭐⭐⭐⭐⭐⭐⭐⭐掌握基础题型
排列组合与概率⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐掌握基础题型
几何问题⭐⭐⭐⭐⭐⭐⭐掌握基本公式
容斥原理⭐⭐⭐⭐⭐必须掌握
最值问题⭐⭐⭐⭐⭐⭐掌握套路
年龄问题⭐⭐⭐⭐⭐必须掌握
日期周期问题⭐⭐⭐⭐⭐掌握基础
溶液问题⭐⭐⭐⭐了解即可
牛吃草问题⭐⭐⭐⭐⭐记住公式

备考策略

  1. 掌握基础题型

    把工程、经济利润、容斥、年龄等简单题型学透，这些是必拿分的。考试时先扫一遍，挑这些简单题做。

  2. 学会代入排除法

    数量关系是选择题，很多题目不需要硬算，把选项代进去验证可能更快。年龄问题、多位数问题、余数问题优先用代入排除。

  3. 掌握方程法

    方程法是最通用的方法，虽然可能不是最快的，但最稳妥。熟练掌握一元一次方程、二元一次方程的解法。

  4. 数字特性法

    利用奇偶特性、倍数特性、尾数特性快速排除选项，提高解题速度。

  5. 有舍有得

    10-15道题中，一般有5-6道简单题，3-4道中等题，2-3道难题。把简单和中等的做对，难题直接蒙，数量关系就不会拖后腿。

数量关系时间分配：建议给数量关系留10-15分钟。先花1分钟扫一眼所有题，挑出3-5道最简单的做，保证做对。剩下的题蒙同一个选项（比如都蒙B或都蒙C），这样正确率大概在30-40%，已经够用了。

六、行测5大模块：判断推理

题型概述

判断推理主要考查对各种事物关系的分析推理能力，涉及对图形、语词概念、事物关系和文字材料的理解、比较、组合、演绎和归纳等。题量大、技巧性强、提分快。

题型题量特点提分难度
图形推理10题看图找规律，技巧性强⭐⭐⭐
定义判断10题给定义找匹配，考查理解能力⭐⭐
类比推理10题找词语间逻辑关系，阅读量小⭐⭐
逻辑判断10题形式逻辑+论证推理，难度最大⭐⭐⭐⭐

图形推理

图形推理是判断推理中最有意思也最让人头疼的题型。掌握规律后其实很简单。

核心考点

  1. 位置规律

    元素组成相同看位置。考点：平移、旋转、翻转。

  2. 样式规律

    元素组成相似看样式。考点：遍历、加减同异、黑白运算。

  3. 属性规律

    元素组成不同且不相似，先看属性。考点：对称性、曲直性、开闭性。

  4. 数量规律

    元素组成不同，属性没规律，看数量。考点：点、线、面、素、角。

  5. 空间重构

    折纸盒、拆纸盒问题。方法：相对面、相邻面、画边法。

  6. 特殊规律

    功能元素、图形间关系、平面拼合等。

解题思路

  • 图形相同 → 看位置（平移、旋转、翻转）
  • 图形相似 → 看样式（遍历、加减同异、黑白运算）
  • 图形不同 → 先属性（对称、曲直、开闭）→ 后数量（点、线、面、素）
  • 空间类 → 相对面、相邻面、画边法

定义判断

定义判断是给一个或多个定义，然后从选项中找出符合或不符合定义的答案。

  • 解题步骤：看清楚问"属于"还是"不属于" → 找定义中的关键词（主体、客体、方式、目的、原因、结果、条件）→ 选项与定义逐一比对
  • 常见陷阱：偷换主体、偷换客体、偷换概念、无中生有
  • 提速技巧：多定义题，问哪个定义先看哪个，其他定义可以先不看

类比推理

类比推理是给出一组相关的词，找出与之在逻辑关系上最为贴近或相似的词。

常见逻辑关系

关系类型具体内容例子
语义关系近义、反义、比喻义、象征义高兴：开心；勤奋：懒惰
逻辑关系全同、并列、包含、交叉、对应北京：中华人民共和国首都；苹果：水果
语法关系主谓、动宾、偏正学生：学习；打扫：卫生
  • 解题技巧：先看一级关系（语义/逻辑/语法），再看二级辨析（感情色彩、词性、程度、自然/人工、必然/或然等）
  • 造句法：把两个词造成句子，看选项是否也能造成同样结构的句子
  • 常见陷阱：顺序反了、关系搞错了、常识不足

逻辑判断

逻辑判断是判断推理中难度最大的部分，包括形式逻辑和论证推理两大类。

形式逻辑

  • 翻译推理：先翻译后推理。记住"如果...那么..."前推后，"只有...才..."后推前。掌握逆否等价、德摩根定律。
  • 组合排列：题干给出一组对象和信息，要求进行匹配。方法：排除法、代入法、列表法、最大信息法。
  • 真假推理：几个人说话，有真有假，判断谁说真话谁说假话。方法：找矛盾关系（必有一真一假）、找反对关系。

论证推理

  • 加强型：最常见的是搭桥（论据和论点之间建立联系）和补充论据。
  • 削弱型：最常见的是否定论点、拆桥、否定论据、另有他因、因果倒置。
  • 解题步骤：找论点 → 找论据 → 分析论证方式 → 看选项（加强/削弱）
  • 力度比较：直接加强/削弱 > 间接加强/削弱；必然性 > 可能性

七、行测5大模块：资料分析

题型概述

资料分析主要考查对各种形式的文字、图表等资料的综合理解与分析加工能力。这是行测中最容易拿满分的模块，也是提分最快的模块。

  • 题量：4篇资料，每篇5题，共20题
  • 特点：套路性强、提分快、性价比最高
  • 目标：正确率85%以上，最好能全对

速算技巧

  1. 截位直除法

    除法运算时，根据选项差距决定截取几位有效数字。选项差距大（首位不同），分子分母都截两位；选项差距小（首位相同），分母截三位。

  2. 特殊分数法

    把百分数转化为特殊分数，简化计算。例如：50%=1/2，33.3%≈1/3，25%=1/4，20%=1/5，16.7%≈1/6，14.3%≈1/7，12.5%=1/8，11.1%≈1/9，10%=1/10。

  3. 分数比较

    一大一小直接看（分子大分母小的分数大）；同大同小看速度（分子增长快的分数大）。

  4. 尾数法

    加减法运算中，选项尾数不同时，只算尾数即可。

  5. 估算法

    选项差距大时，可以大胆估算，不用精确计算。

高频考点

考点考查频率核心公式/方法
增长率计算⭐⭐⭐⭐⭐r = (现期-基期)/基期
增长量计算⭐⭐⭐⭐⭐增长量 = 现期/(1+r) × r （特殊分数法）
基期量计算⭐⭐⭐⭐基期 = 现期/(1+r) （截位直除）
比重计算⭐⭐⭐⭐⭐现期比重 = 部分/整体
基期比重⭐⭐⭐⭐基期比重 = 现期比重 × (1+整体增长率)/(1+部分增长率)
两期比重比较⭐⭐⭐⭐部分增长率 > 整体增长率，比重上升；反之下降
平均数计算⭐⭐⭐⭐平均数 = 总量/份数
平均数增长率⭐⭐⭐(a-b)/(1+b) （a是分子增长率，b是分母增长率）
倍数计算⭐⭐⭐是几倍 = A/B；多几倍 = A/B - 1
综合分析⭐⭐⭐⭐⭐每篇最后一题，四个选项逐一判断
资料分析提分秘诀：资料分析是行测中唯一可能拿满分的模块。提分方法就是：① 记住所有公式和术语；② 熟练掌握速算技巧；③ 大量刷题，每天做2-4篇。坚持一个月，正确率从50%提升到90%完全没问题。

做题注意事项

  • 先看问题再找数据：带着问题去材料里找，不要先读材料
  • 注意时间和单位：看清是同比还是环比，单位是否一致（亿元vs万元）
  • 不要硬算：能估算就估算，能排除就排除
  • 综合分析题策略：先看简单的选项，难的选项先跳过；按照CDBA的顺序看
  • 避免常见陷阱：时间陷阱、单位陷阱、概念陷阱、范围陷阱

八、申论备考全攻略

申论五大题型

1. 归纳概括题

归纳概括题是申论的基础题型，也是必考题型。要求从给定材料中提炼、概括出要点。

  • 常见设问：概括问题、原因、影响、做法、经验、特点等
  • 评分标准：全面、准确、简洁、有条理
  • 解题步骤：审题（明确概括对象和范围）→ 找点（回到材料找相关要点）→ 加工（同类合并、异类罗列）→ 书写（分条作答，用序号标清）
  • 提分关键：答案全部来自材料，不要自己瞎编；宁滥勿缺，要点尽量全

2. 提出对策题

提出对策题要求针对材料中的问题，提出解决的对策建议。

  • 常见设问：提出对策、建议、措施、方案等
  • 对策来源：① 材料中直接给的对策（摘抄）；② 问题原因反推对策；③ 经验教训转化为对策
  • 对策要求：针对性（针对问题）、可行性（能落地）、可操作性（具体怎么做）
  • 常见对策角度：思想观念、制度机制、监督管理、人才队伍、资金投入、技术手段、宣传教育

3. 综合分析题

综合分析题是申论中难度较大的题型，要求对材料中的某句话、某个现象进行分析。

  • 常见类型：词语解释型、句子理解型、观点评价型、比较分析型、启示型
  • 答题思路：是什么（解释含义/亮明观点）→ 为什么（分析原因/影响/理由）→ 怎么办（提出对策/总结升华）
  • 核心方法：围绕核心话题，从材料中找所有相关的信息点，按照逻辑组织答案

4. 贯彻执行题（应用文写作）

贯彻执行题考查应用文写作能力，是近年来申论考试的重点，分值高、形式多样。

  • 常见文种：倡议书、宣传稿、讲话稿、调研报告、建议书、公开信、通知、短评、导言等
  • 格式要素：标题、称谓、正文、落款（发文机关+日期）。注意不同文种格式不同
  • 正文结构：开头（背景/目的）→ 主体（主要内容，根据文种和题目要求确定）→ 结尾（呼吁/总结）
  • 提分关键：格式分不能丢；内容要点来自材料；语言符合文种风格

5. 大作文（议论文写作）

大作文是申论的重头戏，分值最高，也是拉分的关键。要求根据给定材料，自选角度，自拟题目，写一篇议论文。

评分标准

档次分值标准
一类文32-40分立意明确，见解深刻，结构完整，逻辑严谨，语言流畅，论证充分
二类文24-31分立意明确，结构完整，逻辑清晰，语言通顺，论证较充分
三类文16-23分立意基本明确，结构较完整，语言基本通顺，论证不够充分
四类文15分以下立意不明确，结构不完整，语病较多，字数不够

写作步骤

  1. 第一步：立意（确定中心论点）

    仔细审题，结合材料，确定文章的核心观点。立意要准确、明确、深刻。

  2. 第二步：拟题（拟定标题）

    标题要体现中心论点，简洁有力。常用方法：对仗式、比喻式、主副标题式。

  3. 第三步：结构（搭建框架）

    五段三分式最稳妥：开头（引出论点）+ 三个分论点段落 + 结尾（总结升华）。

  4. 第四步：论证（充实内容）

    每个分论点都要有论据支撑。论据可以来自材料，也可以用自己积累的素材。论证方法：举例论证、道理论证、对比论证、引用论证。

  5. 第五步：书写（落笔成文）

    字迹工整，卷面整洁，不涂改。字数控制在要求范围内（一般1000-1200字）。

申论备考方法

  • 多做真题：申论真题至少做3遍，每一遍都有新收获
  • 重视小题：小题占60分，是拉分的关键。大作文分差反而不大
  • 积累素材：关注人民日报评论、半月谈、学习强国，积累金句和案例
  • 练字：字写得好，申论至少多拿3-5分。每天练15分钟字
  • 多动笔写：不要只看不写，一定要自己动手写答案，然后对照参考答案修改
  • 材料为王：申论答案80%来自材料，不要脱离材料自己瞎写

九、选岗技巧

考得好不如报得好。选岗直接决定了你的竞争激烈程度和上岸概率。

选岗原则

  1. 限制条件越多越好

    岗位限制条件越多，符合条件的人越少，竞争越小。优先选择有专业限制、学历限制、工作经验限制、政治面貌限制的岗位。三不限岗位竞争最激烈，慎选。

  2. 招的人多的岗位优先

    招2个人的岗位比招1个人的岗位进面概率大。招1个人的岗位，万一碰到一个学霸，你就没机会了。招多个人的岗位，进面机会更多。

  3. 避开热门地区和热门部门

    一线城市、省会城市、核心部门（两办、组织部、纪委）竞争非常激烈。如果实力不是特别强，可以考虑地级市、县乡基层岗位或者相对冷门的部门。

  4. 结合自身优势选岗

    如果你是党员、有基层工作经验、有专业证书，那就选有这些限制条件的岗位，把竞争者过滤掉。

  5. 不要盲目追求"好"岗位

    很多人盯着"好岗位"报，结果扎堆炮灰。有时候，能考上的岗位就是最好的岗位。先上岸再图发展。

选岗步骤

  1. 下载职位表：公告发布后，下载职位表Excel文件
  2. 筛选条件：用筛选功能，按专业、学历、政治面貌、工作经验等条件筛选
  3. 初步备选：筛出自己符合条件的岗位，列出清单
  4. 对比分析：对比各岗位的招录人数、部门、地区、发展前景
  5. 观望报名人数：报名期间每天看报名人数统计，避开过热岗位
  6. 最终报名：在报名截止前1-2天确定最终岗位，完成报名
报名注意事项：① 不要最后一天才报名，万一审核不通过就没机会改了；② 报名信息要如实填写，弄虚作假会被记入诚信档案；③ 缴费成功才算报名完成，不要忘记缴费。

十、备考规划与避坑

6个月备考计划

阶段时间任务每日学习时长
基础阶段第1-2个月系统学习行测5大模块和申论各题型的基础知识和解题方法4-5小时
强化阶段第3-4个月分模块刷题，强化技巧，提升速度和正确率5-6小时
真题阶段第5个月做历年真题，整套模考，查漏补缺6-7小时
冲刺阶段第6个月回顾错题，模拟考试，调整状态5-6小时

各阶段详细规划

基础阶段（2个月）

  • 跟着视频课系统学习，每个模块逐一攻克
  • 边学边做笔记，整理知识框架
  • 每学完一个模块，做对应的练习题巩固
  • 学习顺序建议：资料分析 → 判断推理 → 言语理解 → 数量关系 → 常识判断
  • 申论同步开始，先学习各种题型的答题方法

强化阶段（2个月）

  • 分模块大量刷题，每个模块刷1000题以上
  • 建立错题本，分析错题原因
  • 开始限时训练，提高做题速度
  • 申论开始动笔写，每周做1-2套申论题
  • 积累申论素材和作文金句

真题阶段（1个月）

  • 做近10年国考真题和近5年目标省份的省考真题
  • 严格按照考试时间模拟，上午行测下午申论
  • 做完后认真分析，统计各模块正确率
  • 找到薄弱环节，针对性强化

冲刺阶段（1个月）

  • 回顾错题本和笔记，查漏补缺
  • 每周做2-3套模拟题，保持做题手感
  • 调整作息，按照考试时间安排学习
  • 关注时政热点，积累申论素材
  • 保持良好心态，不要焦虑

备考避坑

  1. 不要只听课不刷题

    听课是被动学习，刷题才是主动学习。很多人听了很多课，感觉都懂了，一做题就错。听完课一定要大量刷题，把方法内化为自己的能力。

  2. 不要盲目刷题不总结

    刷题不是目的，掌握方法才是。做完题一定要总结，分析错题原因，找出自己的薄弱点，针对性改进。错题本比新题更有价值。

  3. 不要偏科

    行测五个模块都不能放弃。数量关系和常识可以少花时间，但不能完全不学。申论更不能放弃，很多人行测高分申论拉胯，照样上不了岸。

  4. 不要忽视真题

    真题是最好的复习资料，质量远高于模拟题。真题至少做3遍：第一遍按模块做，第二遍整套做，第三遍只做错题。

  5. 不要不列计划

    备考是一个漫长的过程，没有计划很容易懈怠。制定详细的学习计划，每天完成什么任务，每周达到什么目标，心里要有数。

  6. 不要和别人比进度

    每个人的基础和学习效率不同，进度快慢不代表最终成绩。按自己的节奏来，扎实学好每一个知识点。

  7. 不要只注重行测忽略申论

    很多考生把90%的时间花在行测上，申论只花10%，结果申论拖后腿。行测拉分难，申论拉分容易。得申论者得天下。

  8. 不要熬夜学习

    公考备考是持久战，身体是革命的本钱。保持规律作息，每天高效学习8小时，比熬夜学习12小时效果好得多。

  9. 不要轻易放弃

    公考竞争激烈，一次上岸是少数，很多人考了好几次才上岸。坚持下去，不断总结提升，总有一天会上岸的。

  10. 不要把考公当成唯一出路

    保持平常心，考公只是众多职业选择中的一个。努力了就不后悔，即使没考上，备考过程中学到的知识和能力也是你的财富。

最后想说：公务员考试是一场实力+运气的较量。实力是基础，运气是加分项。我们能做的就是不断提升自己的实力，机会来的时候才能牢牢抓住。愿每一个努力的人都能得偿所愿，成功上岸！
