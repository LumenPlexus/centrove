一、考试简介

为什么考计算机二级

全国计算机等级考试（National Computer Rank Examination，简称NCRE），是由教育部教育考试院主办的全国性计算机水平考试。二级证书是大学期间最值得考的证书之一。

  • 毕业要求：很多高校将计算机二级与学位证挂钩，要求必须通过才能毕业
  • 求职加分：简历上有二级证书，尤其是Office类，能体现办公软件能力，增加就业竞争力
  • 考公/考编：部分公务员和事业单位岗位要求计算机二级证书
  • 技能提升：通过备考系统学习Office技能，对今后的学习和工作都很有帮助
  • 保研/评优：部分学校保研、评奖学金时会将证书作为加分项
  • 落户加分：部分城市积分落户政策中，计算机二级可以加分

报考条件

计算机二级考试报考条件非常宽松，几乎没有门槛：

  • 不受年龄、职业、学历等背景限制，任何人都可以报考
  • 考生可以根据自己学习情况和实际能力选考相应的级别和科目
  • 不需要先考一级，可以直接报考二级
  • 可以同时报考多个科目（只要考试时间不冲突）

证书用途

用途说明
学业方面部分学校可抵计算机公共课学分、毕业要求、保研加分
就业方面简历加分、部分岗位硬性要求、体现办公软件能力
职业发展考公/考编/评职称的加分项或必备条件
实用技能Word/Excel/PPT 是职场必备技能，学好终身受益

各科目详细分析

MS Office 高级应用

特点：报考人数最多，市场认可度最高，实用性最强。考查Word、Excel、PPT三个软件的高级应用。

优势：适用面广，不管什么专业、什么工作都能用得上；找工作时最有说服力。

劣势：操作题题量大，考试时间紧张；Excel函数部分有一定难度。

推荐指数：⭐⭐⭐⭐⭐（绝大多数人选这个）

WPS Office 高级应用

特点：2021年新增科目，考查WPS文字、WPS表格、WPS演示三大组件。与MS Office类似，但操作更简单。

优势：难度相对较低，通过率更高；WPS在国内越来越普及。

劣势：题库相对较少，备考资料不如MS Office丰富；企业认可度略低于MS Office。

推荐指数：⭐⭐⭐⭐（追求稳过的可以选）

Python 语言程序设计

特点：近年来越来越热门的科目，考查Python编程基础。

优势：Python是当前最火的编程语言，就业前景好；语法简洁，入门相对容易。

劣势：需要编程思维，零基础入门有一定门槛；对非计算机专业实用性不如Office。

推荐指数：⭐⭐⭐⭐（对编程感兴趣或想转行IT的推荐）

C语言

特点：经典编程语言，计算机专业常考。

优势：语法严谨，学好C语言再学其他语言更容易；计算机专业基础课。

劣势：难度大，通过率低；指针、内存等概念对初学者不友好。

推荐指数：⭐⭐⭐（计算机专业或想打基础的推荐）

选科建议：① 非计算机专业学生，优先选MS Office，最实用、认可度最高；② 如果只想简单拿证，可以选WPS Office或Python；③ 计算机专业学生，建议选C语言或Python，与专业课相辅相成；④ 想转行做程序员的，选Python或Java。

三、考试形式与分值

考试形式

  • 考试方式：无纸化上机考试（全部在电脑上完成）
  • 考试时长：120分钟
  • 满分：100分
  • 及格线：60分
  • 证书等级：60-79分合格，80-89分良好，90-100分优秀

题型与分值（以MS Office为例）

题型题量分值说明

Word 备考重点

  1. 样式是重中之重

    样式是Word的核心功能，也是考试的高频考点。要掌握：新建样式、修改样式、应用样式、样式集、样式的导入导出。目录的生成也依赖于标题样式。

  2. 分节符是难点

    很多考生搞不清分页符和分节符的区别。分节符可以实现不同节有不同的页面设置、不同的页眉页脚。这是长文档排版的基础，必须掌握。

  3. 页眉页脚有坑

    页眉页脚经常和分节符结合考查。注意"链接到前一条页眉"按钮，取消链接才能设置不同的页眉页脚。奇偶页不同、首页不同也是常考点。

  4. 邮件合并必考

    邮件合并几乎是每次考试都考的内容。要掌握：建立主文档、选择数据源、插入合并域、预览结果、完成合并。

  5. 目录自动生成

    目录必须用Word自动生成功能，不能手动输入。先设置好标题样式，然后引用 → 目录 → 自动目录。修改文档后要更新目录。

Word 答题技巧

  • 按顺序做题：Word题的小问题之间通常有先后逻辑关系，按顺序做不容易出错
  • 仔细读题：每个小问题都要看清楚要求，不要漏做
  • 善用查找替换：批量修改格式用查找替换，效率高还不容易漏
  • 格式刷：相同格式可以用格式刷快速复制
  • 及时保存：做几步就按Ctrl+S保存一下，防止意外

必考函数详解

1. IF 函数（条件判断）

语法：=IF(条件, 条件成立时的值, 条件不成立时的值)

示例：=IF(A1>=60,"及格","不及格")

扩展：IF函数可以嵌套使用，实现多条件判断。例如：=IF(A1>=90,"优秀",IF(A1>=80,"良好",IF(A1>=60,"及格","不及格")))

2. SUMIF / SUMIFS（条件求和）

SUMIF 语法：=SUMIF(条件区域, 条件, 求和区域)

示例：=SUMIF(A:A,"销售部",B:B) （求销售部的销售额总和）

SUMIFS 语法：=SUMIFS(求和区域, 条件区域1, 条件1, 条件区域2, 条件2, ...)

示例：=SUMIFS(B:B,A:A,"销售部",C:C,"张三") （求销售部张三的销售额）

3. VLOOKUP（查找引用）

语法：=VLOOKUP(查找值, 查找区域, 返回第几列, 匹配方式)

  • 查找值：要找什么
  • 查找区域：在哪里找（查找值必须在区域的第一列）
  • 返回第几列：找到后返回第几列的值
  • 匹配方式：0/FALSE 精确匹配，1/TRUE 近似匹配

示例：=VLOOKUP(A2, 学生信息!A:C, 3, 0) （在学生信息表中查找A2对应的第三列数据）

VLOOKUP 常见错误：① 查找值不在查找区域的第一列；② 返回列数是相对于查找区域的列数，不是整个工作表的列数；③ 精确匹配必须写0或FALSE；④ 查找区域要锁定（加$），否则下拉公式时区域会偏移。

4. 排名函数 RANK

语法：=RANK(数值, 引用区域, 排序方式)

示例：=RANK(A2, A$2:A$100, 0) （求A2在A2:A100中的降序排名）

5. 日期函数 DATEDIF

语法：=DATEDIF(开始日期, 结束日期, 单位)

单位："Y" 年数差，"M" 月数差，"D" 天数差

示例：=DATEDIF(A2, TODAY(), "Y") （计算年龄）

数据透视表

数据透视表是Excel最强大的功能之一，也是考试的必考内容。

  • 创建步骤：选中数据 → 插入 → 数据透视表 → 选择放置位置 → 拖拽字段到行/列/值/筛选器
  • 值字段设置：可以设置求和、计数、平均值、最大值、最小值等
  • 分组：日期可以按年/月/日分组，数字可以按区间分组
  • 筛选：可以对行标签、列标签进行筛选
  • 常见考点：创建数据透视表、设置值字段、数据分组、添加计算字段

Excel 备考建议

  1. 函数是重点也是难点：把常用函数的用法、参数、例子都记熟，每个函数至少练5遍
  2. 理解比记忆重要：不要死记硬背函数语法，要理解每个参数的含义，知道什么时候用什么函数
  3. 数据透视表必须掌握：分值高，操作相对固定，是必拿分的
  4. 多动手操作：Excel是练出来的，不是看出来的。每个函数、每个功能都要自己亲手操作几遍
  5. 刷题找感觉：把题库里的Excel题都做一遍，熟悉各种题型和坑

PPT 备考重点

  1. 幻灯片母版

    母版是PPT的核心概念，也是考试重点。母版可以统一设置所有幻灯片的格式。视图 → 幻灯片母版，进入母版视图后可以修改母版和版式。

  2. 动画效果

    动画是常考点。要掌握：添加动画（进入、强调、退出、动作路径）、动画窗格（调整顺序、设置持续时间和延迟）、触发器动画。

  3. 超链接与动作按钮

    超链接可以链接到其他幻灯片、其他文件、网页等。动作按钮是内置的按钮，设置更方便。这两个功能经常结合考查。

  4. SmartArt 图形

    SmartArt可以快速将文字转化为图形。要掌握：插入SmartArt、转换SmartArt类型、添加/删除形状、修改颜色和样式。

  5. 节的使用

    节用于组织幻灯片，类似文件夹。可以新建节、重命名节、删除节、移动节。这是比较新的考点，经常考到。

PPT 提分秘诀：PPT是最简单的操作题，目标是拿满分。备考方法就是把题库里所有PPT题都做一遍，每个功能亲手操作。考试时仔细读题，不要漏看任何一个小要求，确保每个操作都到位。

八、选择题备考

选择题共20题，每题1分，共20分。分为公共基础知识（10题）和计算机基础（10题）两部分。

公共基础知识

公共基础知识是所有二级科目都要考的内容，包括数据结构与算法、程序设计基础、软件工程基础、数据库设计基础四大部分。

选择题备考策略

  1. 刷题库是王道

    选择题题库相对固定，原题重复率很高。把题库里的选择题都刷一遍，记住答案，考试时大概率能碰到原题。

  2. 重点突破公共基础

    公共基础知识比较难理解，也是很多考生失分的地方。建议听一遍视频讲解，理解基本概念，然后刷题记忆。

  3. 计算机基础靠积累

    计算机基础相对简单，很多都是常识性问题。平时多了解计算机相关知识，考前刷题巩固即可。

  4. 利用碎片时间

    选择题适合利用碎片时间刷，比如排队、坐车、睡前，刷个10道20道，积少成多。

  5. 错题反复看

    做错的题要标记出来，反复看，直到记住为止。错题是提分的关键。

选择题的"隐形门槛"：虽然官方没有明确说选择题必须达到多少分，但实际考试中确实存在操作题做得很好但选择题太低导致不及格的情况。建议选择题至少拿到10分以上，保险起见最好拿12-15分。

九、备考方法与时间规划

备考时间规划

备考时长每日学习时间适合人群通过率
2个月1-2小时有一定Office基础较高
1个月2-3小时Office基础较好中等
2周4-5小时基础好、学习能力强有风险
1周6-8小时学霸/临时抱佛脚看运气

详细备考计划（以2个月为例）

第一阶段：基础学习（第1个月）

  • 第1周：Word

    学习Word所有考点，跟着视频边看边操作。每天1-2小时，学完后做2-3套Word真题。

  • 第2周：Excel

    重点攻克函数和数据透视表，每个函数都要亲手练。Excel是难点，多花点时间。每天2小时，学完做2-3套Excel真题。

  • 第3周：PPT + 选择题

    PPT比较简单，一周足够。同时开始刷选择题，每天刷20-30道。

  • 第4周：专项突破

    针对自己的薄弱环节重点练习。函数不行就练函数，Word的邮件合并不会就练邮件合并。

第二阶段：刷题冲刺（第2个月）

  • 第5-7周：整套刷题

    开始整套做真题，Word+Excel+PPT一套一套地做。刚开始可能需要2-3小时才能做完一套，慢慢提速。每天做1-2套，做完后对照答案改分，把不会的操作研究明白。

  • 第8周：模考冲刺

    严格按照考试时间（120分钟）做模拟考试，训练时间分配。回顾错题，查漏补缺。选择题集中冲刺，把题库刷完。

备考方法

  1. 操作题一定要自己动手做

    看视频、看答案都不算会，只有自己亲手操作出来才算真的会。很多人看的时候觉得"这么简单"，自己一做就各种找不到按钮、记不住步骤。

  2. 用题库软件练习

    一定要用模拟考试系统的题库软件练习，熟悉考试环境和操作方式。推荐：未来教育、虎奔等题库软件。

  3. 真题是最好的复习资料

    计算机二级考试是从题库里抽题的，原题重复率非常高。把题库里的题都做会了，通过考试基本没问题。

  4. 建立错题/难题清单

    做错的题、不会的题，都记下来，反复练习。同一道题做对三次以上，才算真正掌握。

  5. 合理分配时间

    三个操作题的时间分配建议：Word 30分钟、Excel 45分钟、PPT 20分钟、选择题 15分钟、检查 10分钟。Excel最难，给最多时间；PPT最简单，少花时间。

备考核心秘诀：刷题！刷题！刷题！计算机二级是操作性考试，熟能生巧。把题库里的30-40套题都做一遍，做错的再做一遍，通过考试就是水到渠成的事。

十、考试注意事项与避坑

考前准备

  • 带齐证件：准考证和身份证是必带的，缺一不可
  • 提前踩点：如果考场不熟悉，建议提前一天去看看，避免考试当天找不到地方
  • 提前到场：提前30-40分钟到考场，有充足时间签到、入座
  • 饮食注意：考试当天不要吃太油腻或太辣的食物，避免肠胃不适
  • 休息充足：前一天晚上早点睡，保证充足睡眠

考试流程

  1. 进入考场，找到自己的座位号
  2. 输入准考证号登录考试系统
  3. 确认考生信息无误
  4. 阅读考生须知和操作说明
  5. 点击"开始考试"，开始计时（120分钟倒计时）
  6. 先做选择题，再做操作题（也可以自己安排顺序）
  7. 做完后点击"交卷"，确认交卷
  8. 离开考场

答题技巧

  1. 先做选择题，再做操作题

    选择题只能进一次，退出后就不能再改了。所以先把选择题做完、检查好，再退出做操作题。

  2. 操作题先易后难

    建议答题顺序：PPT（最简单，先拿分）→ Word（次之）→ Excel（最难，放最后）。把能拿的分先拿到手。

  3. 仔细读题，不要漏做

    每道操作题都有好几个小问题，一个一个对着做，做完一个打个勾，确保不漏做。漏做是最可惜的失分。

  4. 不会的先跳过

    碰到不会的操作，不要死磕，先做后面会的。等其他题都做完了，再回来研究不会的。时间有限，先保证会的都做对。

  5. 及时保存

    做几步就按Ctrl+S保存一下。万一电脑出问题，至少不会白做。考试结束前一定要确认文件保存成功。

常见问题处理

问题处理方法
电脑死机/黑屏立即举手示意监考老师，不要自己乱动
软件打不开从考生文件夹里打开文件，不要直接从软件里打开
找不到文件看清楚题目说的文件名和保存位置，一般在考生文件夹下
功能找不到用搜索框搜索功能名称，或在选项卡中仔细找
时间不够先做会的、分值高的，难题直接放弃

备考避坑

  1. 不要只看视频不操作

    "一看就会，一做就废"是很多考生的通病。视频是别人在操作，你看了不代表你会了。一定要自己亲手操作，练到肌肉记忆。

  2. 不要只刷题不总结

    做了很多题，但做错的还是错，等于白做。做完题一定要总结，分析错误原因，把不会的知识点搞懂。

  3. 不要放弃选择题

    很多人觉得选择题只有20分，不重要。但实际上选择题可能有"隐形分数线"，太低了会影响总成绩。花点时间刷选择题，性价比很高。

  4. 不要轻视PPT

    PPT虽然简单，但也有很多细节容易丢分。比如动画顺序不对、超链接没连上、SmartArt类型选错等等。目标是拿满分，就不能掉以轻心。

  5. 不要死磕Excel难题

    Excel的某些函数确实很难，考试时如果碰到不会的函数，先跳过，把其他简单的分先拿到。不要在一道题上花太多时间。

  6. 不要用WPS练MS Office

    虽然两者功能类似，但界面和操作还是有区别的。考什么版本就用什么版本练习，避免考试时找不到功能。

  7. 不要临时抱佛脚

    计算机二级虽然不算太难，但也不是随便看看就能过的。至少预留1-2个月的备考时间，稳扎稳打。

  8. 不要忘记保存文件

    这是最低级也是最致命的错误。做了半天没保存，等于零分。养成随手按Ctrl+S的好习惯。

最后想说：计算机二级是一个付出就有回报的考试。它不需要你有多聪明，只要你肯花时间练习，把题库里的题都做会，通过考试是水到渠成的事情。加油，祝你一次通过！
