一、简历的作用与HR筛选逻辑

1.1 简历的作用

简历不是你的人生自传，而是一份"营销材料"——你要通过这份材料，说服HR给你一个面试机会。

  • 敲门砖：简历是你和公司的第一次接触，决定了你能不能拿到面试
  • 自我介绍：让HR在最短时间内了解你的背景和能力
  • 面试提纲：面试时，面试官是拿着你的简历提问的，简历内容决定了面试的走向

1.2 6秒定律

什么是6秒定律？
据研究，HR平均只花6秒钟扫一份简历，就决定要不要继续看下去。如果6秒内没有看到感兴趣的内容，这份简历就直接被pass了。

这意味着什么？意味着你的简历必须：

  1. 重点突出：最重要的信息要放在最显眼的位置（上半部分）
  2. 简洁明了：废话少说，每一句话都要有价值
  3. 排版清晰：结构清楚，让HR一眼就能找到他想看的
  4. 匹配岗位：HR找的是"适合这个岗位的人"，不是"最优秀的人"

1.3 HR在简历里找什么

  • 你是谁：基本信息、教育背景
  • 你做过什么：实习经历、项目经历、校园经历
  • 你能做什么：技能、证书、成就
  • 你和岗位匹配吗：相关经验、核心能力、岗位要求
核心原则：岗位匹配
简历不是写你有多牛，而是写你有多适合这个岗位。每投一个岗位，都要针对性地修改简历，突出和岗位相关的经历和技能。海投同一份简历，效果会差很多。

二、简历结构与各部分写法

一份标准的简历包含以下模块，按重要性排序：

2.1 个人信息

放在最顶部，简洁明了。

必备可选不要写
姓名 照片（证件照，不要自拍） 身份证号
手机号 求职意向/目标岗位 家庭住址
邮箱（专业一点） 个人作品集/博客/GitHub链接 身高体重（除非岗位要求）
所在城市 到岗时间 政治面貌（除非国企/考公）
注意：邮箱不要用什么 love123@qq.com 这种昵称邮箱，用名字拼音或学号邮箱更专业。照片一定要用正式的证件照，不要用生活照、自拍照。

2.2 教育背景

应届生的教育背景很重要，放在个人信息后面。

  • 格式：学校名称 + 专业 + 学历 + 就读时间
  • 绩点：高就写（3.5/4.0以上或专业前20%），不高就不写
  • 核心课程：写和岗位相关的3-5门课，不要列一堆不相关的
  • 获奖：奖学金、竞赛奖项可以在这里简要提及（也可以单独列获奖经历模块）

2.3 实习经历（最重要！）

这是简历的核心，也是HR最关注的部分。有相关实习经历，你的简历就成功了一半。

实习经历写法公式

公司名称 + 职位 + 时间（标题行）

工作描述：用3-5个bullet point描述你做了什么、怎么做的、取得了什么成果

要点：

  • 每一条都用动词开头（负责、参与、主导、策划、优化、分析...）
  • 用数据量化成果（提升了XX%、完成了XX个、覆盖了XX人）
  • 突出和岗位相关的经历，无关的一笔带过或不写
  • 按时间倒序排列（最近的放最前面）

2.4 项目经历

如果实习经历少，可以用项目经历来补。课程项目、竞赛项目、个人项目都可以写。

  • 项目名称 + 角色 + 时间
  • 项目简介：一句话说清楚项目是做什么的
  • 你的职责：你在项目中负责什么，做了什么
  • 项目成果：项目取得了什么成果，你贡献了什么

2.5 技能证书

  • 语言技能：英语四六级、雅思托福、小语种等（注明分数或水平）
  • 计算机技能：Office、编程、设计软件等（注明熟练程度）
  • 专业证书：CPA、法考、教师资格证等
  • 其他技能：驾照、摄影、剪辑等，有亮点的可以写

2.6 校园经历

学生会、社团、班干部、志愿服务等。如果实习和项目经历已经很丰富了，这部分可以简化。

  • 只写有亮点的，不要罗列一堆水经历
  • 突出你的能力：组织能力、沟通能力、领导力等
  • 同样要用STAR法则和量化表达

三、STAR法则详解

3.1 什么是STAR法则

STAR法则是描述经历的黄金结构，让你的经历既有故事性又有说服力。

字母含义说明
S - Situation 情境 这件事是在什么背景下发生的？
T - Task 任务 你的任务/目标是什么？
A - Action 行动 你具体做了什么？怎么做的？
R - Result 结果 最后取得了什么成果？（一定要量化！）

3.2 正反例对比

❌ 反面例子（太笼统，没有细节）

负责公众号运营，写了很多文章，粉丝增长很快。

✅ 正面例子（STAR结构+量化）

【S/T】负责部门官方微信公众号的内容运营，目标是提升粉丝量和文章阅读量。
【A】独立策划选题，撰写原创推文，优化排版和标题，每周更新3篇。
【R】3个月内粉丝从2000增长到5000（+150%），单篇最高阅读量达8000+，平均打开率从3%提升到8%。

❌ 反面例子（只有职责，没有成果）

参与了XX营销活动的策划和执行。

✅ 正面例子（突出行动和成果）

【S/T】作为核心成员参与公司618营销活动策划，负责社交媒体推广部分。
【A】独立撰写5篇推广文案，设计互动活动方案，协调3个KOL合作。
【R】活动期间相关话题曝光量超500万，带来新用户2000+，转化率达15%，超额完成目标。

STAR法则使用要点：
① S和T要简洁，重点在A和R
② Action部分是核心，要具体说明"你"做了什么，而不是"我们"做了什么
③ Result部分一定要量化，用数字说话
④ 简历里不用每次都完整写S/T/A/R，可以灵活组合，但结构要清晰

四、量化表达技巧

"用数据说话"是简历的第一法则。同样的经历，量化和不量化，效果天差地别。

4.1 哪些可以量化

维度示例
规模覆盖用户10万+ / 管理10人团队 / 预算50万
效率将效率提升30% / 节省时间50% / 减少成本20%
增长粉丝增长150% / 销售额增长80% / 用户增长2倍
数量撰写文章50篇 / 完成项目8个 / 处理订单1000+
排名专业排名3/120 / 比赛获一等奖 / 销量全国TOP10
时间提前3天完成 / 连续3个月达标 / 实习6个月

4.2 量化表达公式

公式1：动词 + 工作内容 + 方法 + 结果
例：通过优化关键词策略（方法），将搜索排名从第5页提升到第1页（结果）

公式2：在X时间内，做了X事，取得了X成果
例：3个月内（时间），独立运营公众号（事），粉丝从2000增长到5000（成果）

公式3：带领X人团队，完成X项目，达成X目标
例：带领5人小组（团队），完成校园推广项目（项目），获客3000+（目标）
注意：量化要基于事实，可以适当包装但不能造假。面试时HR会深挖细节，如果是编的很容易露馅。实在没有精确数字，可以用估算的，但要合理。

五、不同专业简历侧重点

5.1 技术岗（开发/算法/测试等）

  • 核心：技术能力 + 项目经验
  • 重点写：技术栈、项目经历（用了什么技术、解决了什么问题、性能提升多少）、GitHub链接、技术博客
  • 技能栏：详细列出掌握的编程语言、框架、工具，注明熟练程度
  • 建议：准备一个个人作品集，展示你做过的项目

5.2 产品岗

  • 核心：产品思维 + 项目经历 + 数据分析能力
  • 重点写：产品相关实习/项目（需求分析、产品设计、数据分析、项目推进）
  • 加分项：自己做的产品分析报告、竞品分析、原型设计
  • 技能：Axure、Figma、SQL、数据分析工具

5.3 运营岗

  • 核心：运营经验 + 数据成果
  • 重点写：用户运营/内容运营/活动运营经历，一定要用数据说话（增长了多少、转化率多少、ROI多少）
  • 加分项：自己的公众号/小红书/B站账号、运营案例
  • 技能：文案能力、数据分析、社群运营、活动策划

5.4 市场岗

  • 核心：营销经验 + 创意能力 + 数据意识
  • 重点写：市场推广、品牌活动、媒介投放、内容营销等经历
  • 加分项：成功的营销案例、创意作品、文案作品集
  • 技能：营销策划、文案撰写、数据分析、PPT制作

5.5 行政/人力岗

  • 核心：细致认真 + 沟通协调 + 办公技能
  • 重点写：行政/人力相关实习、学生工作（组织活动、管理团队、服务同学）
  • 加分项：大型活动组织经验、流程优化案例
  • 技能：Office三件套（尤其Excel和PPT）、沟通能力、组织协调能力

六、简历避坑20条

  1. 简历超过1页：应届生1页足够，除非你有10年以上工作经验
  2. 排版花里胡哨：用彩色模板、奇怪字体，反而喧宾夺主。简洁专业最重要
  3. 照片不专业：放自拍、生活照、过度P图的照片，很减分
  4. 写"个人评价"："性格开朗、学习能力强"这种空话，HR根本不信
  5. 全是职责描述：只写"负责XX工作"，没有做了什么和取得什么成果
  6. 没有量化：通篇都是"参与了XX""负责了XX"，一个数字都没有
  7. 经历和岗位不相关：投运营岗却写了一堆家教经历，HR不关心
  8. 时间顺序混乱：一定要按倒序排列，最近的经历放最前面
  9. 有错别字：一个错别字就可能让你被pass，写完一定要检查
  10. 格式不统一：字体大小不一、对齐混乱、标点不统一，显得不专业
  11. 用生僻字体：你的电脑有，HR电脑可能没有，打开就乱了
  12. 文件命名不规范："简历.pdf"不行，要写"姓名-应聘岗位-简历"
  13. 发Word格式：不同版本Word打开格式会乱，一定要发PDF
  14. 虚假信息：可以包装但不能造假，背调会查，面试也会露馅
  15. 套话空话："具有较强的沟通能力和团队协作精神"，谁都会写
  16. 兴趣爱好写太多："喜欢看书、听音乐、旅游"，和岗位无关的别写
  17. 中英文混杂：除非是外企或必要的专业术语，不然别乱夹英文
  18. 海投同一份简历：不同岗位的要求不同，简历也要有针对性地改
  19. 不看JD就投：连岗位要求都不看，简历怎么可能匹配
  20. 不检查就发：有错别字、格式错乱、甚至投错公司名字，低级错误致命

七、简历投递渠道与注意事项

7.1 主要投递渠道

渠道特点适合人群
校园招聘 最靠谱，企业直接到学校招人，应届生身份有优势 应届生
企业官网 最直接，大公司都有自己的招聘官网，信息最准 所有求职者
招聘APP BOSS直聘、前程无忧、智联招聘、猎聘等，选择多 社招+校招
内推 成功率最高，可以直接到HR或部门手里 有资源的同学
LinkedIn 外企和大厂比较多，适合中高端岗位 有经验的求职者

7.2 投递注意事项

  • 邮件标题要规范：姓名 - 应聘岗位 - 学校 - 可到岗时间
  • 附件命名要规范：姓名-应聘岗位-简历.pdf
  • 正文不要空：简单写几句自我介绍和求职意向，不要只发附件
  • 选对时间：工作日上午9-10点或下午2-3点发邮件，被看到的概率更高
  • 不要重复投递：同一家公司同一个岗位不要投好几次
  • 做好记录：用表格记录投了哪些公司、什么时候投的、进展如何
内推是最好的渠道：
找学长学姐、亲戚朋友、LinkedIn上的人帮你内推，成功率比海投高得多。不要不好意思开口，大部分人都愿意帮忙的。内推不仅简历更容易被看到，有些公司还会给内推人奖金，双赢。

八、求职信怎么写

8.1 求职信的作用

求职信（Cover Letter）是附在简历前面的一封信，用来说明你为什么申请这个岗位、为什么你是合适的人选。不是所有公司都要求，但写得好的求职信能大大加分。

8.2 求职信的结构

  1. 称呼：尊敬的HR/招聘负责人，如果知道名字就直接写名字
  2. 开头段：你是谁，从哪里看到的招聘信息，申请什么岗位（1-2句）
  3. 中间段1：为什么你适合这个岗位——结合你的经历和能力，对应岗位要求（2-3句）
  4. 中间段2：为什么选择这家公司——表达对公司的了解和向往（1-2句）
  5. 结尾段：感谢阅读，表达面试期望，留下联系方式（1-2句）
  6. 落款：此致 敬礼 / 顺颂商祺 + 姓名 + 日期

8.3 求职信写作要点

  • 控制篇幅：300-500字，不要太长，HR不会仔细看
  • 针对性强：每封求职信都要针对具体公司和岗位，不能通用
  • 不要重复简历：求职信是补充，不是简历的复制粘贴
  • 展示热情：让HR感受到你对这个岗位和公司的热情
  • 突出匹配度：重点讲你和岗位要求的匹配点
求职信模板（精简版）：

尊敬的XX公司HR：

您好！我是XX大学XX专业的应届毕业生XXX，从XX渠道了解到贵公司正在招聘XX岗位，特此投递简历。

在校期间，我曾在XX公司实习，负责XX工作，取得了XX成果（1-2个核心亮点，和岗位要求对应）。我具备XX、XX等能力，相信能够胜任该岗位的工作。

我一直关注XX公司的发展，非常认同贵公司的XX理念/产品，希望能有机会加入。

随信附上我的简历，期待能有机会与您进一步交流。感谢您的时间！

此致
敬礼

XXX
XXXX年XX月XX日
