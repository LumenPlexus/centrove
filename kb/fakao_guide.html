一、法考是什么

考试简介

国家统一法律职业资格考试（简称"法考"），前身是国家司法考试，是司法部统一组织的从事法律职业的资格考试。通过法考后，可从事律师、法官、检察官、公证员、法律顾问、仲裁员等法律职业，是法律行业的"敲门砖"。

法考分为客观题考试和主观题考试两部分，必须先通过客观题才能参加主观题。客观题成绩两年内有效，即第一年过了客观题但主观题没过，第二年可以直接参加主观题考试。

报名条件

条件类型具体要求
学历要求全日制普通高等学校法学类本科学历并获得学士及以上学位；或全日制普通高等学校非法学类本科及以上学历，并获得法律硕士、法学硕士及以上学位；或全日制普通高等学校非法学类本科及以上学历并获得相应学位且从事法律工作满三年
专业要求2018年4月28日前已入学或已取得相应学历的人员，仍可按"老人老办法"报考（非法学专业也可考）
国籍要求具有中华人民共和国国籍
品行要求拥护中华人民共和国宪法，享有选举权和被选举权，具有良好的政治、业务素质和道德品行
年龄限制无年龄上限
"新人新办法，老人老办法"：2018年4月28日《国家统一法律职业资格考试实施办法》实施前已入学或已取得相应学历的高等学校法学类专业本科及以上学历毕业生，或者高等学校非法学类专业本科及以上学历毕业生并具有法律专业知识的，仍然可以报名参加法考。

证书含金量

  • 法律行业准入证：律师、法官、检察官、公证员等职业的必备证书
  • 就业面广：可进入公检法司、律所、企业法务、金融机构等多个领域
  • 薪资水平高：法律职业普遍薪资高于社会平均水平，资深律师年薪百万很常见
  • 社会地位高：法律职业在社会中享有较高的职业声望和社会地位
  • 职业寿命长：越老越吃香，经验和人脉积累的价值持续增长
  • 转行跳板：很多人通过法考实现职业转型，从其他行业跨入法律领域

二、考试结构详解

客观题考试

客观题考试共两卷，分为试卷一和试卷二，每卷100道题，满分各150分，总分300分。全国合格分数线一般为180分。

试卷科目分值占比题型
试卷一习近平法治思想、法理学、宪法、中国法律史、国际法、司法制度和法律职业道德、刑法、刑事诉讼法、行政法与行政诉讼法150分单选50题×1分 + 多选/不定项50题×2分
试卷二民法、知识产权法、商法、经济法、环境资源法、劳动与社会保障法、国际私法、国际经济法、民事诉讼法（含仲裁制度）150分单选50题×1分 + 多选/不定项50题×2分

主观题考试

主观题考试为一卷，包括案例分析题、法律文书题、论述题等题型，满分180分。全国合格分数线一般为108分。考试时长为4小时。

题型题量分值说明
论述题1题约35分习近平法治思想相关，必做
刑法案例分析1题约30分必做
刑诉法案例分析1题约25分必做
民商诉综合案例1题约50分必做，民法+商法+民诉综合
选做题（行政/商法二选一）1题约28分选做一道，行政法或商法
注意：主观题考试提供法律法规汇编电子版（即电子法条），可以在考试系统中检索查阅。所以主观题不要求死记硬背法条，但要熟悉法条位置和关键词检索方法。

四、三轮复习规划

第一轮：精讲阶段（3月-5月，约3个月）

目标：全面学习8个科目的基础理论，建立知识体系框架，理解所有核心概念和制度。

  • 学习内容：跟着精讲课程和精讲教材，逐科系统学习
  • 学习方法：听课+看书+做配套真题
  • 时间安排：每天3-5小时，民法刑法各2周，其他科目各1-1.5周
  • 重点：理解为主，不要急于背诵，搞懂每一个知识点
  • 配套练习：每学完一章做一章的真题，检验学习效果
科目建议学习时长学习要点
民法18-20天物权、合同、侵权是重点，体系性强
刑法15-18天犯罪论、刑罚论、重点罪名，注重理解
民诉10-12天管辖、证据、程序流程，对比记忆
刑诉12-14天程序多、细节多，梳理流程图
行政法10-12天行政行为、行政复议、行政诉讼
商经知12-15天公司法是核心，经济法散而多
理论法10-12天法理学重理解，宪法重记忆
三国法6-8天分值少但好拿分，不要放弃

第二轮：真题背诵阶段（6月-8月，约3个月）

目标：大量刷真题，强化高频考点，开始背诵重点内容，提高做题速度和准确率。

  • 真题刷题：做近10年真题，至少刷2-3遍
  • 背诵强化：使用背诵卷/内部讲义，重点记忆高频考点
  • 错题整理：建立错题本，分析错题原因
  • 分科突破：针对薄弱科目重点突破
  • 模拟测试：每周进行1-2次模拟考试，训练时间分配
黄金法则：真题是最好的复习资料。法考重者恒重，高频考点反复考。把真题吃透，比看十本新书都管用。建议真题至少刷3遍：第一遍分科做，第二遍按年做，第三遍只做错题。

第三轮：冲刺模考阶段（8月-9月，约1.5个月）

目标：全真模拟考试，查漏补缺，调整状态，冲刺高分。

  • 全真模考：严格按照考试时间做整套模拟题，适应考试节奏
  • 聚焦重点：放弃偏难怪题，只看高频考点和易错点
  • 背诵冲刺：使用考前背诵版资料，反复记忆核心考点
  • 错题回顾：集中复习错题本，避免考试中犯同样错误
  • 心态调整：保持良好作息，不要熬夜，调整到最佳状态

五、8大科目特点与复习顺序

推荐复习顺序

民法 → 刑法 → 民诉 → 刑诉 → 行政法 → 商经知 → 理论法 → 三国法

理由：先实体后程序，先难后易，先高分值后低分值。民法刑法是基础，理解性强，适合先学；诉讼法需要记忆，放中间；理论法和三国法记忆性强、分值相对低，放后面。

各科目特点详解

1. 民法

特点：分值最高，体系庞大，内容繁多，与生活联系紧密，理解难度中等。民法典出台后体系更加清晰。

核心考点：物权编（所有权、用益物权、担保物权）、合同编（合同订立、效力、履行、违约责任）、侵权责任编、婚姻家庭编、继承编。

复习建议：建立民法体系思维，从"人-物-债-责任"的逻辑框架理解。重点掌握物权与合同，这两部分占民法分值的70%以上。多做案例题，培养法律关系分析能力。

2. 刑法

特点：理论性强，学说争议多，入门难但入门后提分快。注重逻辑推理和案例分析。

核心考点：犯罪构成（四要件/三阶层）、因果关系、正当防卫、共同犯罪、犯罪形态、刑罚裁量、重点罪名（侵犯财产罪、侵犯人身权利罪、贪污贿赂罪）。

复习建议：跟准一个老师的学术观点，不要纠结不同学说的争议。重点掌握犯罪论体系和常见罪名的认定。多做案例分析，训练定罪思维。

3. 民事诉讼法

特点：程序法，知识点琐碎但规律性强，对比记忆效果好。性价比较高。

核心考点：管辖、当事人、证据、一审程序、二审程序、再审程序、执行程序、仲裁制度。

复习建议：画流程图梳理诉讼程序全貌。注意与刑诉、行政诉讼的区别，对比记忆。掌握管辖和证据两大重点板块。

4. 刑事诉讼法

特点：程序最复杂、细节最多的科目，"程序之王"。记忆量大，但有规律可循。

核心考点：管辖、回避、辩护、证据、强制措施、侦查程序、审查起诉、一审程序、二审程序、死刑复核程序、审判监督程序、执行程序。

复习建议：按照诉讼流程（立案→侦查→起诉→审判→执行）串联知识点。利用口诀和表格记忆易混淆点。特别注意证据和辩护制度。

5. 行政法与行政诉讼法

特点：离生活较远，抽象概念多，但考点集中，重复性强。

核心考点：行政行为（行政许可、行政处罚、行政强制）、行政复议、行政诉讼（受案范围、管辖、被告、举证责任）、国家赔偿。

复习建议：重点掌握行政诉讼法，占行政法分值的一半以上。理解"官管民，民告官"的基本逻辑。对比行政复议和行政诉讼的异同。

6. 商经知（商法+经济法+知识产权法）

特点：知识点分散，涉及法律众多，但每部法律考得比较浅。公司法是绝对重点。

核心考点：公司法（设立、股东权利、组织机构、股权转让、解散清算）、合伙企业法、破产法、票据法、反垄断法、反不正当竞争法、劳动法、著作权法、专利法、商标法。

复习建议：抓大放小，重点攻克公司法（占商法一半分值）。经济法部分利用口诀快速记忆。知产部分理解+记忆结合。

7. 理论法（法理学+宪法+中国法律史+法治思想+司法制度）

特点：内容抽象，但分值不低。法理学重理解，宪法重记忆。

核心考点：法理学（法的本体、法的运行、法与社会）、宪法（公民基本权利、国家机构、立法法）、习近平法治思想、司法制度和法律职业道德。

复习建议：法理学注重理解核心概念，宪法用口诀和表格记忆。习近平法治思想是主观题论述题的必考内容，必须重视。

8. 三国法（国际公法+国际私法+国际经济法）

特点：分值最低，但考点集中，得分率高。放弃可惜，学了就能拿分。

核心考点：国际公法（国际法主体、国家责任、条约法）、国际私法（法律适用、涉外民事关系）、国际经济法（国际贸易术语、国际货物买卖合同、WTO）。

复习建议：不要放弃三国法，性价比很高。重点掌握国际私法的法律适用规则和国际经济法的贸易术语。考前突击记忆效果好。

八、客观题备考技巧

答题技巧

  1. 排除法：先排除明显错误的选项，缩小选择范围
  2. 矛盾法：两个选项矛盾的话，正确答案通常在其中一个
  3. 绝对化排除：出现"一律""所有""全部""绝对"等绝对化表述的选项往往是错的
  4. 关键词法：抓住题干中的关键词，快速定位考点
  5. 常识判断：有些选项明显不符合常理，可以直接排除

时间分配

题型题量建议时间单题时间
单选题50题约60分钟约1分钟/题
多选题35-40题约70分钟约1.5-2分钟/题
不定项选择题10-15题约40分钟约2-3分钟/题
涂卡+检查—约10分钟—
重要提醒：客观题考试时间非常紧张，平均每道题不到2分钟。平时一定要限时训练，提高做题速度。遇到不会的题先跳过，不要死磕，把会做的题都做完再说。

提高正确率的方法

  • 审题要仔细：注意题干中的"不""错误""不正确""除外"等否定词
  • 相信第一感觉：不确定的题目不要轻易改答案，第一感觉往往是对的
  • 标记难题：拿不准的题做个标记，有时间再回头看
  • 陷阱识别：注意"应当"和"可以"的区别，注意数字、时间、主体等细节
  • 多做真题：真题做多了，出题套路就熟悉了

九、主观题备考技巧

主观题与客观题的区别

维度客观题主观题
考察方式选择判断，识别正确答案书写表达，论证法律观点
能力要求理解+记忆+判断理解+记忆+分析+表达
答题方式涂答题卡键盘打字（机考）
法条检索不提供提供电子法条
时间压力较紧张非常紧张（4小时）

论述题备考

论述题主要考习近平法治思想，是主观题的第一题，也是最容易准备的一道题。

  • 背诵模板：准备几篇万能模板，考前背熟
  • 素材积累：积累法治思想的核心表述和金句
  • 结构清晰：总-分-总结构，每段开头有中心句
  • 字数要求：一般要求600字以上，建议写800-1000字
  • 控制时间：论述题控制在30-40分钟内完成

案例分析题备考

  1. 先读问题，再读案情：带着问题读案例，有针对性地找信息
  2. 边读边标记：在题干上标记关键事实和法律点
  3. 拆解法律关系：梳理清楚人物关系和法律关系
  4. 三段论答题：结论（是什么）+ 法律依据（为什么）+ 事实分析（怎么对应）
  5. 法条定位：学会使用电子法条，快速找到依据
三段论答题法：① 结论先行（先答结论）；② 法律依据（引用法条或法理）；③ 事实分析（结合案情具体分析）。这样答题条理清晰，容易踩中得分点。

电子法条使用技巧

  • 熟悉目录结构：知道每部法律在哪个分类下
  • 关键词检索：学会用关键词快速定位法条
  • 重点法条记位置：高频法条要记住大概位置，节省检索时间
  • 不要每题都查：会的题直接写，不确定的再查，时间宝贵

时间分配建议

十、备考避坑10条

  1. 不要频繁换老师

    每个老师的体系和方法不同，频繁切换会导致知识体系混乱。选定一位老师就跟到底，全程跟下来效果最好。

  2. 不要只听课不做题

    听课是被动接收，做题才是主动输出。很多人听课时感觉都懂了，一做题就错，就是因为缺乏练习。听完一章必须做一章的题。

  3. 不要忽视真题，盲目做模拟题

    真题是最好的复习资料，法考重者恒重，高频考点反复考。模拟题质量参差不齐，不要舍本逐末。真题至少做3遍。

  4. 不要死磕偏难怪题

    法考是通过性考试，60分万岁。把时间花在高频考点上，性价比最高。偏难怪题考的概率很低，不值得花太多时间。

  5. 不要放弃小法

    三国法、理论法、经济法这些"小法"，虽然每科分值不高，但加起来分值可观。而且这些科目记忆性强，考前突击效果好，放弃太可惜。

  6. 不要贪多求全，资料买太多

    资料不在多而在精。一套精讲+一套真题+一套背诵版就够了。把一套资料吃透，胜过买十套新书。

  7. 不要熬夜学习，透支身体

    法考备考是一场马拉松，不是百米冲刺。保持规律作息，每天学习效率比学习时长更重要。熬夜学习只会适得其反。

  8. 不要和别人比进度

    每个人的基础和学习方法不同，进度快慢不代表最终结果。按自己的节奏来，扎扎实实学好每一个知识点才是王道。

  9. 不要忽视主观题备考

    很多人客观题考完才开始准备主观题，结果时间不够用。建议客观题后期就开始穿插主观题练习，培养法律写作能力。

  10. 不要轻言放弃

    法考通过率虽然不高，但每年弃考的人也很多。坚持到最后，你就已经赢了一半。只要方法正确、坚持到底，通过法考只是时间问题。

最后想说：法考是一场持久战，也是一场心理战。它考验的不只是你的法律知识，更是你的毅力、耐心和自我管理能力。相信自己，踏实前行，你一定可以拿到那本梦寐以求的法律职业资格证书！
